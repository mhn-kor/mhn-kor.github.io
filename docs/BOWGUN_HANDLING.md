# 보우건 탄별 반동·장전 기본지식

조사일: 2026-10-12. 탄별 자료는 참고용으로 저장하며, 스타일별 자동 보충 제외 및 헤비 가드 성능 권장만 추천에 연결했다. 탄별 필수 레벨·사격 사이클·피해 배율은 아직 적용하지 않았다.

## 자료의 구분

- 공식 무기 페이지: 무기별 보유 탄, 장전 수, 스킬 미적용 반동·장전 단계의 확인 근거.
- 공식 도움말: 라이트보우건 스타일의 동작·회피 판정 및 대체 가능한 스킬 확인 근거.
- 나우칼: 각 무기의 탄 슬롯별 반동 경감/장전 속도 Lv0~3 적용 결과. 공식 발표값이나 실기 검증 완료값으로 취급하지 않는다.
- 사용자 지침: 어떤 공격을 중심으로 쓸지와 어떤 스킬 투자를 대체할지 결정하는 플레이 지식. 임의 대미지 배율로 바꾸지 않는다.

나우칼 공개 목록의 라이트 56개 무기/140개 탄 슬롯, 헤비 53개 무기/126개 탄 슬롯을 `tools/data/bowgun-handling-reference.json`에 보관했다. 무기 이름·소재 식별자는 원문이며 사이트의 무기 ID와 아직 연결하지 않았다. 같은 탄 이름이 여러 슬롯에 있을 수 있으므로 슬롯 순서·장전 수도 보존한다. 자료의 전체 공식 교차검증은 미완료다.

## 단계와 스킬 레벨은 다르다

반동 단계는 소/중/대/특대, 장전은 빠름/보통/조금 느림/느림을 구분한다. 헤비 용격탄의 `Wyvern` 표시는 특수 반동으로 따로 취급한다. 나우칼 영문 대응은 Low=소, Average=중, High=대, Very High=특대, Fast=빠름, Normal=보통, Slow=조금 느림, Very Slow=느림이다. 공식 도스쟈그라스 무기 페이지의 한국어 단계와 대조했다.

스킬 Lv1이 항상 한 단계 개선을 뜻하지 않는다. Lv2에서만 개선되는 탄도 있고 Lv3을 넣어도 소/빠름에 도달하지 않는 탄도 있다. '최선 단계에 도달하는 최소 레벨'과 '실제 운용에서 요구할 목표 단계'를 구분한다. 아래 표는 이번 나우칼 자료에 관측된 경로이며 모든 미래 무기의 고정 규칙이 아니다.

### 반동 경감 Lv0 → 1 → 2 → 3

| 무기군 | 관측된 단계 변화 | 관측된 최선 단계에 도달하는 최소 Lv |
| --- | --- | --- |
| 라이트 | 소 → 소 → 소 → 소 | 0 |
| 라이트 | 중 → 소 → 소 → 소 | 1 |
| 라이트 | 대 → 대 → 중 → 소 | 3 |
| 라이트 | 특대 → 특대 → 특대 → 대 | 3 (소 도달 불가) |
| 헤비 | 소 → 소 → 소 → 소 | 0 |
| 헤비 | 중 → 소 → 소 → 소 | 1 |
| 헤비 | 대 → 대 → 중 → 소 | 3 |
| 헤비 | 대 → 대 → 중 → 중 | 2 (Lv3 표시 단계 동일) |
| 헤비 | 용격 전용 → 용격 전용 → 용격 전용 → 용격 전용 | 0 (표시 단계 불변) |

라이트의 일반적인 통상·속성 통상탄은 중→소, 관통·산탄은 대→소, 참렬·철갑·확산은 특대→대 경로지만 예외가 있다. 헤비의 통상·속성 통상탄은 소, 관통·산탄은 중→소, 참렬은 대→소, 철갑·확산은 대→중 경로가 대표적이다. 보편적인 탄종 규칙으로 강제하지 말고 무기별 실제 슬롯을 우선한다.

### 장전 속도 Lv0 → 1 → 2 → 3

| 무기군 | 관측된 단계 변화 | 관측된 최선 단계에 도달하는 최소 Lv |
| --- | --- | --- |
| 양쪽 | 빠름 → 빠름 → 빠름 → 빠름 | 0 |
| 양쪽 | 보통 → 빠름 → 빠름 → 빠름 | 1 |
| 양쪽 | 조금 느림 → 조금 느림 → 보통 → 빠름 | 3 |
| 양쪽 | 느림 → 느림 → 느림 → 조금 느림 | 3 (빠름 도달 불가) |
| 헤비 | 조금 느림 → 조금 느림 → 보통 → 보통 | 2 (Lv3 표시 단계 동일) |

같은 탄종도 소재 무기·탄 슬롯에 따라 기본 장전이 다르다. '관통탄=장전3'처럼 탄 이름으로만 결정하면 안 된다. 프레임/시간 미수집 상태이므로 같은 표시 단계가 정확히 같은 시간이라는 가정이나 DPS 배율을 추가하지 않는다.

## 공식 기본 단계와 나우칼 적용 경로의 대조 예시

| 무기·탄 | 기본 반동 / 장전 | 반동 Lv0~3 | 장전 Lv0~3 |
| --- | --- | --- | --- |
| 도스쟈그라스 라이트 · 수냉탄 | 중 / 보통 | 중·소·소·소 | 보통·빠름·빠름·빠름 |
| 도스쟈그라스 라이트 · 참렬수냉탄 | 특대 / 조금 느림 | 특대·특대·특대·대 | 조금 느림·조금 느림·보통·빠름 |
| 도스쟈그라스 헤비 · 수냉탄 | 소 / 보통 | 소·소·소·소 | 보통·빠름·빠름·빠름 |
| 도스쟈그라스 헤비 · 수냉산탄 | 중 / 느림 | 중·소·소·소 | 느림·느림·느림·조금 느림 |
| 도스쟈그라스 헤비 · 확산수냉탄 | 대 / 느림 | 대·대·중·중 | 느림·느림·느림·조금 느림 |
| 오로미도로 라이트 · 관통수냉탄 | 대 / 보통 | 대·대·중·소 | 보통·빠름·빠름·빠름 |

예를 들어 도스쟈그라스 헤비의 확산수냉탄만을 기준으로 보면 반동2가 표시상 최선이며, 반동3을 일괄 필수로 요구할 근거가 없다. 그러나 이 무기의 전체 운용 목표는 다른 탄과 스타일까지 검토한 뒤 결정해야 한다.

## 라이트보우건 스타일 지침

사용자가 설명한 운용 지식과 공식 도움말에서 확인한 판정을 결합한다. 스타일이 몬스터별 속성·회심·역회심·탄종 투자 방향을 대체하지 않는다. 확보한 장비 여유를 해당 무기 특성에 맞는 공격 후보에 투자한다.

| 운용 | 반동 경감 | 장전 속도 | 별도 조건 |
| --- | --- | --- | --- |
| 기본 스타일 | 사용 탄에 맞게 확보 | 사용 탄에 맞게 확보 | 전체 탄 순환/주력 탄 결정 필요 |
| 스텝샷 · 탄 순환 | 스텝샷으로 대체 | 사용 탄에 맞게 확보 | 스텝샷 중심 사격 가정 |
| 스텝샷 · 특정 탄 반복 | 스텝샷으로 대체 | 회피 장전으로 대체하는 방향 | 회피 장전·주력 탄 선택 필요, 확률 의존 |
| 슬라이딩 리로드 | 사용 탄에 맞게 확보 | 스타일로 대체, 목표 0 | 한 발 이상 사용 후 회피로 다음 탄 장전 |

### 스텝샷

- 탄이 남아 있을 때 전후좌우 방향으로 스텝하면서 사격한다. 이 이동은 회피 판정이 아니므로 회피 발동 스킬을 켜는 근거로 사용하지 않는다.
- 스텝샷의 탄별 반동은 동일해지므로 스텝샷 중심 운용에서는 반동 경감 투자를 대체할 수 있다. 일반 탭 사격에는 원래 반동이 남는다. 공식 도움말도 반동이 작은 탄은 탭 사격, 반동이 큰 탄은 스텝샷을 혼용하는 예시를 안내하므로 모든 사격의 반동이 사라지는 것으로 일반화하지 않는다.
- 탄이 0개이면 스텝 입력은 일반 회피가 된다. 이때 회피 장전을 이용해 같은 탄을 보충·반복하는 운용을 사용자가 제시했다.
- 전체 탄 순환형은 장전 속도를 확보하고 빈 반동 경감 투자를 공격·속성 등에 활용한다.
- 특정 탄 반복형은 강한 주력 탄(사용자 예: 확산탄)을 회피 장전으로 보충하여 반동 경감·장전 속도 모두 없이 구성할 수 있다. 주력 탄을 가진 무기에서만 후보를 검토하며 모든 스텝샷에 강제하지 않는다.
- 회피 장전은 확률 발동이므로 무한 보충·항상 성공을 가정하지 않는다. 사용자 목표 레벨, 탄 수·실패 시 대응 및 실제 유지율은 후속 설계에서 확인한다. 스타일만으로 장전 속도가 불필요해진다고 판단하지 않는다.

### 슬라이딩 리로드

- 현재 탄을 한 발 이상 사용한 후 회피하면 다음 탄을 최대 장전 수까지 장전한다. 한 발도 사용하지 않은 상태의 입력은 사용자 설명에 따라 일반 회피 운용으로 기록한다.
- 공식 도움말은 저스트 회피 시 다음 탄을 최대 장전 수보다 한 발 더 장전한다고 안내한다. 이를 전투 내내 유지하는 조건으로 가정하지 않는다.
- 장전 속도 투자 대신 스타일을 이용하는 방향이므로 목표 장전 속도0, 반동 경감은 실제 사용할 탄의 경로에 맞춘다.
- 탄을 빠르게 넘겨 원하는 탄을 고르는 운용과 몬스터별 탄 구성·공격 스킬을 결합한다. 남은 탄을 모두 쏘는 순환형과 동일한 운용 비율로 고정하지 않는다.
- '목표0'은 다른 유효 스킬과 함께 붙은 장전 속도 방어구를 금지한다는 뜻이 아니다.

### 회피 장전 공식 레벨

| Lv | 회피 시 보충 확률 | 성공 시 보충 개수 |
| --- | --- | --- |
| 1 | 30% | 1 |
| 2 | 50% | 1 |
| 3 | 50% | 2 |
| 4 | 70% | 2 |
| 5 | 70% | 3 |

공식 효과 대상은 건랜스·차지액스·라이트·헤비지만 스텝샷 조합 지침은 라이트에만 적용한다. 헤비는 아래 사용자 운용 지침을 별도로 검토한다.

## 헤비보우건 스타일 지침

2026-10-12 사용자 설명을 저장한다. 아래 동작·판정과 권장 레벨은 사용자 운용 지식이며 공식 도움말 교차검증 완료값으로 취급하지 않는다. 사이트 스타일 이름은 `가드리로드` / `앉아쏘기`이며 크라우칭은 앉아쏘기의 별칭으로 기록한다.

### 공통 기본 가드

헤비는 기본 가드 기능이 있다. 아무 입력이 없을 때 앞선 동작의 후딜이 끝난 다음부터 가드 판정이 있다는 사용자 설명을 보존한다. 사격·장전 등 행동 중에도 항상 가드가 유지된다고 가정하지 않는다.

| 운용 | 반동 경감 | 장전 속도 | 별도 투자·조건 |
| --- | --- | --- | --- |
| 가드리로드 | 사용 탄에 맞게 확보 | 스타일로 대체, 목표0 | 가드 성능 Lv2~3 검토 |
| 앉아쏘기 · 탄 순환 | 앉아쏘기로 대체, 목표0 | 사용 탄에 맞게 확보 | 앉아쏘기 중심 사격 |
| 앉아쏘기 · 특정 탄 반복 | 앉아쏘기로 대체, 목표0 | 회피 장전으로 대체하는 방향 | 회피 장전·주력 탄 보유 확인 |
| 앉아쏘기 · 회피/SP 연계 | 앉아쏘기로 대체, 목표0 | 회피 장전으로 대체하는 방향 | 용격탄 보유, 절대 회피·특수 게이지 가속·회피 장전 |

### 가드리로드

- 홀드하면 가드리로드의 가드 자세를 취한다. 이 상태에서 몬스터 공격을 가드하면 현재 남은 탄이 강화된다는 사용자 설명을 기록한다.
- 홀드 중 아래 스와이프로 가드리로드 동작을 한다. 공격 타이밍에 맞춰 이 동작으로 막으면 가드하면서 다음 탄종을 장전한다.
- 공격을 막지 않고 홀드 중 아래 스와이프만 해도 다음 탄종으로 넘어간다. 다음 탄 장전을 위해 반드시 가드 성공이 필요한 것으로 제한하지 않는다.
- 가드리로드 중심 운용은 모든 탄종의 장전 동작이 고정이라는 사용자 기준에 따라 장전 속도 목표0으로 검토한다. 고정 시간(초/프레임)을 임의로 부여하지 않는다.
- 가드를 활용하므로 가드 성능 Lv2~3을 보통의 검토 범위로 둔다. 모든 몬스터에 대한 충분조건이나 확정된 필수 최소2로 강제하지 않는다. 자동빌드의 강제 최소/목표 레벨은 적용 설계 시 확인한다.
- 반동 경감은 대체하지 않으므로 실제 사용하는 탄별 요구를 유지한다. 여유 장비는 몬스터 무기의 속성·회심·역회심·주력 탄에 맞게 투자한다.
- 남은 탄 강화의 배율·지속·적용 범위·가드 조건은 아직 수집하지 않았다. 강화가 항상 발동한다거나 임의의 피해 보너스가 존재한다고 계산하지 않는다.

### 크라우칭 / 앉아쏘기

- 홀드하면 현재 탄으로 앉아쏘기 자세를 취해 연사한다. 이 사격은 모든 탄에서 반동 없이 쏜다는 사용자 설명에 따라 반동 경감 목표0을 검토한다. 일반 사격까지 같은 판정이라고 확장하지 않는다.
- 전체 탄을 순환한다면 다음 탄 장전을 위한 장전 속도 요구는 실제 사용 탄에 맞게 남겨 둔다. 앉아쏘기만으로 장전 속도가 대체된다고 판단하지 않는다.
- 회피 장전을 조합하면 반동이 강한 특정 탄(사용자 예: 용격탄)을 회피로 보충해 반복하는 방향을 검토할 수 있다. 이때 반동 경감·장전 속도 모두 투자하지 않는 구성이 가능하다는 사용자 지침을 기록한다.
- 공격 투자형: 회피 장전을 확보하고 여유 부위를 대미지·속성·회심 등 해당 무기에 유효한 스킬에 투자한다.
- 회피/SP 연계형: 용격탄 보유 헤비에서 절대 회피 + 특수 게이지 가속 + 회피 장전 조합을 검토한다. 사용자 원문 '특수게이지가속'의 실제 스킬명과 절대 회피의 작동 관계·레벨은 구현 전 확인한다. 다른 탄만 보유한 헤비에 그대로 강제하지 않는다.
- SP 가속은 운용 방향 후보에서 유지하지만 직접적인 대미지 배율을 만들지 않는다. 기존 자동추천의 특수 위력 OFF 원칙도 유지한다. 사용자에 의해 제시된 SP 연계 방향 자체를 삭제한다는 의미는 아니다.
- 회피 장전 실패·탄 고갈·장전 fallback, 앉아쏘기 제약 및 각 스킬의 최소/목표 레벨은 후속 확인 대상이다. 확률 보충을 확정적인 무한 연사나 상시 DPS로 환산하지 않는다.

목표0인 스킬이 다른 유효 스킬과 함께 붙어 있는 장비는 금지하지 않는다. 스타일은 필수 운용 조건을 바꾸고, 몬스터·탄·파라미터는 남은 투자 방향을 정한다. 특정 스타일에 완성된 단일 세팅만 연결하지 않는다.

## 후속 적용 전 확인

현재 적용: 스텝샷·앉아쏘기의 반동 경감, 슬라이딩 리로드·가드리로드의 장전 속도는 자동 보충·우대에서 제외한다. 가드리로드는 가드 성능 목표3을 권장 후보로 포함하되 최소0으로 두며 필수2로 강제하지 않는다. 직접 핵심으로 지정한 스킬과 다른 유효 스킬이 있는 장비는 유지한다. 스타일 기준을 끄면 해당 자동 규칙을 해제한다. 몬스터·파라미터별 기존 투자 방향과 점수 공식은 유지한다.

미반영: 탄별 필수 요구 레벨, 특정 탄 반복/회피 장전·용격탄 SP 연계 방향, 가드 후 탄 강화 및 실제 DPS. 화면에도 탄별 요구는 직접 지정해야 한다는 한계를 안내한다. 참고 JSON은 실행 데이터가 아니다.

1. 전체 탄 순환인지 특정 탄 중심인지, 목표 반동·장전 단계 및 해당 탄 슬롯을 선택한다.
2. 각 탄이 목표에 도달하는 실제 스킬 레벨과 Lv3에서 개선 불가한 단계를 구분한다. 순환형에서 여러 탄의 요구를 합칠 때는 사용 탄 중 최대 요구를 기준 후보로 검토하되 사용자 목표를 확정한다.
3. 스타일이 대체하는 요구만 해제한다. 반동·장전은 사격 사이클 제약이며 피해 한 발에 임의 대미지 배율을 더하지 않는다.
4. 원문 이름을 사이트 무기 ID에 연결하고 공식 탄 구성·기본 단계와 교차검증한다. 이번 자료에 없는 신규 무기는 미확인으로 처리한다.
5. 회피 장전 최소/목표 레벨, 주력 탄 선정 기준, 혼용 탭 사격, 탄별 강화 스킬·폭발 피해 계산·실제 공격 비중을 후속 설계한다.
6. 헤비의 공식 스타일 동작 및 탄 강화, 가드 성능의 강제 최소/목표, 절대 회피·SP 가속 조합의 실제 스킬명과 레벨을 적용 전에 확인한다.
