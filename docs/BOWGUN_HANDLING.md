### 기본스타일: 라이트·헤비 공통

근거: 2026-10-13 사용자 지침. 상태: 탄 요구 및 선택 탄 적용 기준에 구현됨.

1. 실제 사용 탄별 B1의 최소 장전 속도·반동 경감을 먼저 확보한다. 모든 무기에 같은 레벨을 강제하지 않는다.
2. 남은 투자로 해당 탄에 적용되는 대미지 버프를 채용한다.
3. 무기 속성·회심/역회심·강화·파라미터는 W1/W2/W7/W8, 보우건 운용·탄별 효과는 B2/B3/B5를 결합해 공격 투자를 비교한다.
4. 일부 탄에만 유효한 효과를 전체 탄의 상시 배율로 확대하지 않는다. 스타일의 장전·반동 대체 조건은 기본스타일에 복사하지 않는다.

## B3. 특정 탄 반복·용격탄 SP 연계

**조건:** 특정 탄 반복은 스텝샷/앉아쏘기에서 해당 탄 보유 시 선택. SP 연계는 용격탄 보유 앉아쏘기 헤비만 제공한다.

| 효과 | 사용자 기준 | 현재 구현 기준·한계 |
| --- | --- | --- |
| 회피 장전 | 최소4·기본 목표4. Lv5는 추가 장비 비용 때문에 선택 대안 | 기본4→4, 선택적으로4→5. Lv5 겸용 장비 금지 아님 |
| 특수 게이지 가속 | 용격SP에서 Lv3 확보 | 최소/목표3 |
| 특수 게이지 가속【저스트 회피】 | 용격SP에서 Lv3 확보 | 최소/목표3 |
| 절대 회피【SP】 | 실용적인 운용에 Lv3 권장 | 개발 시 연계 성립 최소1·목표3으로 구현. 최소1은 사용자 필수 레벨 지정이 아님 |

- 공격 투자형: 회피 장전 확보 후 여유 장비를 유효 공격·속성·회심 등에 투자.
- 회피/SP형: 절대 회피의 SP 소비 후 두 가속으로 게이지 회복을 보완한다는 사용자 지침. SP 위력OFF가 이 운용 방향이나 가속 후보 삭제를 뜻하지 않음.
- 회피 장전은 확률 보충. 무한 연사·항상 성공·상시 DPS 보장 금지. 실패/탄 고갈/일반 장전 복귀·유지율은 미계산.
- 탄 순환형에 반복형의 장전0 규칙을 복사하지 않는다.
- 반복 탄의 통상·참렬 강화는 선택 탄만 검사. 불일치 조건OFF를 보존해 가져오기; 운용·탄은 빌드 이름에도 기록. 저장 빌드 형식은 변경하지 않음.
- 회피 장전·SP 회복·가드 후 강화를 임의 피해 배율로 만들지 않음.

## B5. 탄종별 스킬·버프 적용

**근거:** 2026-10-12~13 사용자 운용 지침·파생 탄 확인. **상태: 비교 기준 탄의 효과/회심·추천 적합성에 구현됨.** 아래 적용 기준을 공식 전수 검증 완료값으로 취급하지 않는다.

| 효과 | 통상탄 | 관통탄 | 산탄 | 철갑유탄 | 참렬탄 | 용격탄 | 확산탄 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 적정 거리 위력 UP | 적용 | 적용 | 적용 | 불가 | 불가 | 불가 | 불가 |
| 포술 | 불가 | 불가 | 불가 | 적용 | 불가 | 적용 | 불가 |
| 회심·흉회심 | 적용 | 적용 | 적용 | 폭발 대미지 불가 | 적용 | 불가 | 불가 |

- 철갑유탄·참렬탄은 부착 후 터지는 운용이므로 적정 거리 위력 UP 대상에서 제외한다는 사용자 기준이다. 참렬탄의 회심 적용과는 별개다.
- 철갑유탄의 회심 제외는 폭발 대미지에 대한 기준이다. 착탄 초타까지 동일하게 제외한다고 확대하지 않는다.
- 용격탄 반동은 별도 ‘용격탄’ 단계이며 반동 경감 최대 레벨로도 줄지 않는다. 스타일이 사격 반동 투자를 대체하는 조건과 구분한다.
- 탄 순환은 보유 탄별로, 특정 탄 반복은 선택 탄별로 적용 여부를 판단한다. 일부 탄에만 유효한 효과를 모든 탄의 상시 효과로 확대하지 않는다.
- 사용자 확인: 속성 파생 탄도 원래 탄 계열의 적용 기준을 따른다.
- 선호: 통상 < 산탄 < 관통＝참렬 < 용격＝확산. 철갑·기타 탄 순위는 미지정. 선호도를 실제 피해 배율로 환산하지 않는다.
- 전체 탄 순환은 반동·장전 요구를 모든 사용 탄에서 확보한다. 공격 효과 비교에는 선호가 가장 높은 탄(동순위면 원래 목록 순서)을 명시적으로 사용한다. 특정 탄 반복은 사용자 선택 탄을 사용하며, 다른 보유 탄의 효과를 끌어오지 않는다.
- 기준 탄 번호와 조건 체크를 내 빌드·공유 링크에 보존한다. 내 빌드 상세에서 탄을 바꾸거나 기존 무기 전체 기준으로 되돌릴 수 있다. 기존 저장 빌드는 기준 탄을 임의 지정하지 않는다.
- 철갑은 폭발 비교로 표시하며 회심·흉회심을 적용하지 않는다. 미확정: 착탄 초타·탄별 실제 피해·사격 비중·가드 후 강화. 전체 탄 순환 DPS나 고정 사격 비율을 만들지 않는다.

## 부록: 단계·조사 경로

### 단계와 스킬 레벨은 다르다

반동 단계는 소/중/대/특대, 장전은 빠름/보통/조금 느림/느림을 구분한다. 헤비 용격탄의 `Wyvern` 표시는 특수 반동으로 따로 취급한다. 나우칼 영문 대응은 Low=소, Average=중, High=대, Very High=특대, Fast=빠름, Normal=보통, Slow=조금 느림, Very Slow=느림이다. 공식 도스쟈그라스 무기 페이지의 한국어 단계와 대조했다.

스킬 Lv1이 항상 한 단계 개선을 뜻하지 않는다. Lv2에서만 개선되는 탄도 있고 Lv3을 넣어도 소/빠름에 도달하지 않는 탄도 있다. '최선 단계에 도달하는 최소 레벨'과 '실제 운용에서 요구할 목표 단계'를 구분한다. 아래 표는 이번 나우칼 자료에 관측된 경로이며 모든 미래 무기의 고정 규칙이 아니다.

#### 반동 경감 Lv0 → 1 → 2 → 3

| 무기군 | 관측된 단계 변화 | 관측된 최선 단계에 도달하는 최소 Lv |
| --- | --- | --- |
| 라이트 | 소 → 소 → 소 → 소 | 0 |
| 라이트 | 중 → 소 → 소 → 소 | 1 |
| 라이트 | 대 → 대 → 중 → 소 | 3 |
| 라이트 | 특대 → 특대 → 특대 → 대 | 3 (소 도달 불가) |
| 헤비 | 소 → 소 → 소 → 소 | 0 |
| 헤비 | 중 → 소 → 소 → 소 | 1 |
| 헤비 | 대 → 대 → 중 → 소 | 3 |
| 헤비 | 대 → 대 → 중 → 중 | 2 (Lv3 표시 단계 동일) |
| 헤비 | 용격 전용 → 용격 전용 → 용격 전용 → 용격 전용 | 0 (표시 단계 불변) |

라이트의 일반적인 통상·속성 통상탄은 중→소, 관통·산탄은 대→소, 참렬·철갑·확산은 특대→대 경로지만 예외가 있다. 헤비의 통상·속성 통상탄은 소, 관통·산탄은 중→소, 참렬은 대→소, 철갑·확산은 대→중 경로가 대표적이다. 보편적인 탄종 규칙으로 강제하지 말고 무기별 실제 슬롯을 우선한다.

#### 장전 속도 Lv0 → 1 → 2 → 3

| 무기군 | 관측된 단계 변화 | 관측된 최선 단계에 도달하는 최소 Lv |
| --- | --- | --- |
| 양쪽 | 빠름 → 빠름 → 빠름 → 빠름 | 0 |
| 양쪽 | 보통 → 빠름 → 빠름 → 빠름 | 1 |
| 양쪽 | 조금 느림 → 조금 느림 → 보통 → 빠름 | 3 |
| 양쪽 | 느림 → 느림 → 느림 → 조금 느림 | 3 (빠름 도달 불가) |
| 헤비 | 조금 느림 → 조금 느림 → 보통 → 보통 | 2 (Lv3 표시 단계 동일) |

같은 탄종도 소재 무기·탄 슬롯에 따라 기본 장전이 다르다. '관통탄=장전3'처럼 탄 이름으로만 결정하면 안 된다. 프레임/시간 미수집 상태이므로 같은 표시 단계가 정확히 같은 시간이라는 가정이나 DPS 배율을 추가하지 않는다.

### 공식 기본 단계와 나우칼 적용 경로의 대조 예시

| 무기·탄 | 기본 반동 / 장전 | 반동 Lv0~3 | 장전 Lv0~3 |
| --- | --- | --- | --- |
| 도스쟈그라스 라이트 · 수냉탄 | 중 / 보통 | 중·소·소·소 | 보통·빠름·빠름·빠름 |
| 도스쟈그라스 라이트 · 참렬수냉탄 | 특대 / 조금 느림 | 특대·특대·특대·대 | 조금 느림·조금 느림·보통·빠름 |
| 도스쟈그라스 헤비 · 수냉탄 | 소 / 보통 | 소·소·소·소 | 보통·빠름·빠름·빠름 |
| 도스쟈그라스 헤비 · 수냉산탄 | 중 / 느림 | 중·소·소·소 | 느림·느림·느림·조금 느림 |
| 도스쟈그라스 헤비 · 확산수냉탄 | 대 / 느림 | 대·대·중·중 | 느림·느림·느림·조금 느림 |
| 오로미도로 라이트 · 관통수냉탄 | 대 / 보통 | 대·대·중·소 | 보통·빠름·빠름·빠름 |

예를 들어 도스쟈그라스 헤비의 확산수냉탄만을 기준으로 보면 반동2가 표시상 최선이며, 반동3을 일괄 필수로 요구할 근거가 없다. 그러나 이 무기의 전체 운용 목표는 다른 탄과 스타일까지 검토한 뒤 결정해야 한다.
