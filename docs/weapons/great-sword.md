## 기본

- **컨셉:** 모으기 연계 한방
- **공격 유형:** 모아베기 → 강모아베기 → 참모아베기. 모으는 중 태클로 버팀
- **주로 쓰는 스킬:** 속성·상태이상 무기는 차지 마스터, 무속성은 저스트 모으기 해방 우선. 차지 스톡
- **쓰지 않는 스킬:** 미작성
- 방어 투자보다 공격 투자. 태클을 무피해로 가정하지 않는다.
- 차지 마스터의 속성 피해 증가와 상태이상 축적 증가를 구분한다. 축적 증가를 대미지로 합산하거나 모으지 않은 타격에 적용하지 않는다.
- 느린·저타수 무기라 흉회심은 Lv5 한방 고점 방향 우대 검토 (CONCEPTS W2).
- 무속성 무기: 태클로 공격을 받아내며 생기는 작은 대미지(최소 1 이상)로 **앙심**을 켜는 빌드가 있다 (2026-10-17 사용자).

## 수류베기

- **컨셉:** 차지 없는 연속 타격 후 모으기 마무리
- **공격 유형:** 모으기 없이 강류·와류·승류 3타를 로테이션으로 때린 뒤 강모아베기를 차지한다. 시작한 기술부터 차례로 이어진다 (강류 → 와류 → 승류 / 와류 → 승류 → 강류 / 승류 → 강류 → 와류). 3타 후 강모아베기부터는 기본 스타일과 같다 (강모아 → 참모아, 강모아 차지 중 태클 → 참모아 등). 초반 연속 타격으로 상태이상 활용 유리
- **주로 쓰는 스킬:** 별도 필수 없음 (상태이상·흉회심 저투자 비교)
- **쓰지 않는 스킬:** 가드·태클 계열 (앙심 등)
- 기본스타일의 느린·저타수 판단(한방 선호)을 복사하지 않는다. 흉회심은 저투자부터 비교한다.
- **태클:** 3타 → 강모아베기 차지 중에만 쓸 수 있어 활용도가 거의 없다.
- **가드:** 수류베기 자체 가드 기술이 있지만, 로테이션이 완전히 끊기고 후딜이 끝난 대기 상태에서만 쓸 수 있어 일부러 기다렸다 막아야 한다. 자주 쓰지 않아 빌드 활용성이 없다 (2026-10-17 사용자).

## 격앙참

- **컨셉:** 기본과 거의 같은 우선순위
- **공격 유형:** 모아베기 → 강모아베기 → 격앙참. 태클 대신 가드태클
- **주로 쓰는 스킬:** 기본과 동일 + 공격적인 방어 검토 (가드태클)
- **쓰지 않는 스킬:** 미작성
- 가드 성능 요구는 지정되지 않았다.
- 무속성 무기: 차지 중 가드태클 → 격앙참. 가드태클의 가드 성능이 랜스보다 약해 조금씩 닳으므로 **앙심**으로 공격력을 올려 격앙참 대미지를 키우는 빌드가 있다 (2026-10-17 사용자).

## 미확정

- 스킬 최소/목표 레벨·후보 순위·공격별 비중. 권장 후보를 필수 MAX로 바꾸지 않는다.
