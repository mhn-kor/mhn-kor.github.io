# 빌드 컨셉

빌드의 뼈대가 되는 방향(컨셉)과 그 판단 규칙. 정비: 2026-10-16 (기존 `WEAPON_SETTING_GUIDE.md`의 W1·W2·W4·W8을 옮김).

- 문서 지도: 무기·스타일 [WEAPONS.md](WEAPONS.md) / 스킬 [SKILLS.md](SKILLS.md) / 로직·탐색 [AUTO_BUILD.md](AUTO_BUILD.md)

## 빌드를 짜는 순서 (사용자 설명, 2026-10-16)

1. **컨셉 결정:** 빌드의 메인 방향을 먼저 정한다. 이것이 세팅 제안이다.
2. **뼈대 세팅:** 컨셉의 뼈대 스킬은 반드시 들어간다. 레벨과 부위는 선택한다.
   - 뼈대 최소만 가져가고 나머지 스킬을 더 챙기는 안 / 컨셉에 필요한 최대 아웃풋을 내고 나머지를 챙기는 안.
3. **기회비용으로 레벨·부위 결정:** 컨셉을 무너뜨리지 않는 범위에서, 뼈대 스킬을 다른 부위로 옮겼을 때 빈 자리에 더 도움이 되는 스킬이 오면 옮긴다. ([AUTO_BUILD.md A0](AUTO_BUILD.md#a0-기회비용을-고려한-장비-선택))

## 컨셉 일람 (작성 중 · 미확정)

사용자 설명을 그대로 옮긴 초안. 뼈대 최소 기준·적용 무기·'또는' 처리는 확인 후 확정하고, 확정되면 코드 데이터와 1:1로 맞춘다. **현재 실행 로직은 아직 이 표를 쓰지 않는다** (기존 방향 생성 A2 사용).

| 컨셉 | 뼈대 (예시) | 확인 필요 |
| --- | --- | --- |
| 절대 속성치 | 속성 공격 강화5 + 경지 / 하이 차지 / 둘 다 | 하이 차지 사용 무기·체력 가정, 최소 기준 |
| 퍼센트 속성치 | 회심격【속성】, 고룡 속성 버프 | 최소 기준, 회심 확보와의 관계 |
| 부파 대미지 | 파괴왕 + 추격 | 파괴왕 계열은 점수 없이 컨셉 후보로만 (2026-10-17 확정). 최소 기준 |
| 자체 상태이상 | 거품의 춤 / 견인불발 / 겁혈 망토 / 귀화 망토 + 돌파구 (+ 전화위복 Lv1 정도: 상태이상 공백 보충) | 하나만인지 복수인지, 무기 제한 |
| 흉회심 (W2) · 상태이상 무기 (W4) · 회심 (W1) | 아래 규칙 | 컨셉 표 형식으로 옮길지 |

## W1. 회심 보유 무기

**조건 (2026-10-18 사용자, 이전 '자체 회심 20~30% 이상' 기준을 대체):** 회심 세팅 여부는 무기 기본 회심이 아니라 **사용자의 파라미터 선택**으로 판단한다.

- 스타일 강화 파라미터에 회심 +10% 3개를 투자했다면 "이번 세팅은 회심"이라는 의지로 본다 → 기본 회심이 0%라도 회심 방향을 제안한다.
- 기본 회심이 20~30%여도 파라미터를 속성·공격으로 찍었다면 기본 회심은 추가 대미지 정도로만 보고 회심 방향을 잡지 않는다.
- **예외 (변형 공격 강화 중심 무기):** 무기 특성·운용상 변형 공격 강화가 적용되고 빌드의 중심 스킬인 무기는 변형 공격 강화로 회심 80%를 이미 확보하므로, 회심 파라미터 없이 속성 파라미터 3개를 찍는 경우가 있다. 이때는 간파·약점 특효를 1~2개(주로 약점 특효 Lv1 = 회심 20%) 넣어 회심 100%를 맞추는 안을 제안한다.
- **스타일강화를 적용하지 않은 무기 (파라미터 없음):** 기본 회심이 20% 이상이면서 무기 자체 스킬이 회심 관련이거나, 기본 회심이 30% 이상이면 회심 세팅을 고려한다 (2026-10-18 사용자).
- 스타일 레벨업 진행 중(스타일은 바꿨지만 파라미터를 다 찍지 않은 상태)은 따로 고려하지 않는다. 사용자는 최종 결과를 기준으로 세팅한다.
- **미구현:** 현재 로직은 자체 회심 > 0이면 회심 방향을 검토한다.

| 조건 | 검토 방향 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 + 속성 무기 | 회심격【속성】·추가 회심 투자 | 회심 전용 효과 활용. 속성 투자 대안도 유지 |
| 속성 파라미터3 | 속성 중심, 회심은 보조 | 사용자 파라미터를 바꾸지 않음 |
| 일반 속성 없는 물리 무기 + 공격 파라미터3 | 물리 중심 | 상태이상 축적치를 속성 피해로 합산하지 않음 |
| 적은 장비로 높은 회심 확보 가능 | 슈퍼회심 투자 비교 | 필수 조합 아님. 자동 보충은 변형 회심 방향 또는 힘의 해방을 직접 넣었을 때만 |
| 회심 파라미터3 + 자체 회심 | 공격 증강【회심】도 비교 | 회심격 방향만 고정하지 않음 |

- **회심 80%는 필수도 목표도 아니다** (2026-10-14 확정). 자체 회심은 투자를 검토할 근거이며, 추가 회심이 없는 안도 비교한다.
- 회심 기대확률 상한 100%. 100% 확보도 비용과 비교한다.
- 간파 Lv1·약점 특효 Lv1이 가장 효율이 좋다. 슬롯이 2개쯤 비면 둘을 1레벨씩 넣는다. 약점 특효는 록온으로 약점 부위를 노리기 쉬워 간파와 동급으로 본다 (2026-10-17 사용자).
- 슈퍼회심: 기본 1.25 → Lv5 1.5. 회심이 100%에서 멀수록 효율이 떨어져 많이 쓰지 않는다. 변형 공격 강화처럼 높은 회심을 보장하는 스킬이 있을 때, 또는 힘의 해방 발동 조건을 맞출 때 함께 검토한다 (2026-10-17 사용자).
- 변형 공격 강화의 회심+80%는 **해당 공격에만** 적용 (예: 기본20%+80% → 그 공격 100%, 절약한 장비를 슈퍼회심에). 전체 공격의 상시 회심으로 보지 않는다. 차지액스도 대상이지만 같은 운용 비율을 가정하지 않는다.

### 공격 증강【회심】

| 항목 | 규칙 |
| --- | --- |
| 기준 회심 | 무기 자체 + 스타일 강화 + 회심 파라미터. 간파·힘의 해방 등 장비 회심 제외 |
| 증가분 | 착용 시 기준 회심 1%당 공격력 +8. 음수는 0 |
| 예시 | 자체20% → +160 / 자체20%+파라미터30% → +400 |
| 주의 | 고정 증가분까지 곱하는 '공격 활성'과 다른 스킬. 파라미터만으로 증가분 지급 금지, 중복 보너스 금지 |
| 후보 | 강화 후 자체50%는 유력한 검토 사례. 50%를 장착 임계값으로 쓰지 않음. 셀레기오스 머리도 근거 사례일 뿐 강제 장착 아님 |

## W2. 기본 역회심 무기

**조건:** 파라미터 변경 전 자체 회심이 음수. 기본 방향은 흉회심 보완, 사용자 선택 우선.

| 조건·방향 | 규칙 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 | 흉회심 방향·자동 연성 보충 제외 | 최종 회심이 음수여도 역회심 감소 의도로 해석 |
| 흉회심 Lv1 저투자 | 나머지 장비를 다른 효과에 | 손실을 거의 보완 (정확히 1배는 아님) |
| 흉회심 Lv3 균형 / Lv5 고점 | 서로 다른 투자안으로 비교 | 모든 역회심 무기에 Lv5 강제 금지 |
| 빠른·다타수 무기 | 다른 대미지 스킬 효율 우선 비교 | 타격이 많을수록 평균 기대값에 수렴 |
| 느린·한방 무기 (대검 등) | Lv5 한방 고점 방향 우대 검토 | 사용자 선호. 평균 점수에 보너스는 없음 |
| 전심전력 | 낮은 우선순위 비교 후보 | 금지 아님. 실제 점수가 좋으면 채택 |

- 흉회심 1/3/5 방향은 **해당 레벨까지의 투자 비교**다. 최소0에서 시작하고 미채용도 허용한다. 직접 지정한 최소는 유지한다.
- 무기·겸용 장비에 붙은 흉회심은 보존하고 실제 계산한다. 3회심 선택으로 무기·파라미터를 바꾸지 않는다.
- 전심전력: 공격 증가와 회심 감소를 함께 계산. 늘어난 역회심 중 30%만 흉회심, 70%는 0.75배이므로 순수 버프가 아니다. 흉회심 필수 묶음 아님.

**기대값** (r = 최종 역회심 확률, 상한100%, 흉회심 자체 감소 포함)
- 흉회심 없음: 1 − 0.25r / 있음: (1 − r) + 0.3r × 흉회심 배율 + 0.7r × 0.75
- 기본 −30% 예: 없음 0.925 / Lv1(−10%, ×1.5) 0.99 / Lv3(−20%, ×2) 1.0625 / Lv5(−30%, ×2.5) 1.165. Lv5의 250%를 전체 2.5배로 해석하지 않는다.

## W4. 상태이상 무기

**방향:** 축적으로 발동 기회를 만들고, 발동 이점을 실제 피해로 연결한다. 10성의 높은 체력에서는 독 자체 피해만으로 부족하므로 해당 추가 공격을 중요하게 본다 (사용자 판단, 공식 필수 아님).

| 스킬 | 역할 | 기준 |
| --- | --- | --- |
| 독·마비·수면·폭파 공격 강화 | 축적 시 누적량 증가 | 축적 확률 증가와 구분 |
| 기습 상태 이상 | 후방 조건 축적 확률 증가 | 낮은 우선순위. **예외: 건랜스 블래스트 대시** (후방 확보 쉬움) |
| 하룡의 독 안개 / 염왕룡의 폭발가루 | 위치 조건 없는 축적 확률 증가 | 모든 고룡 효과로 일반화 금지 |
| 추가 공격【폭파】 | 축적 확률 + 폭파마다 공격력 증가(최대10회) | 독·마비 지속 피해와 구분 |
| 상태 이상 축적 시 위력 UP | 축적이 발생한 그 타격의 피해 증가 | 축적 확률 증가·최종 발동 순간 효과가 아님 |
| 추가 공격【독】·【마비】 | 해당 상태 몬스터에게 피해 증가 | 상태 중 공격 가능 시간 검토. 상시 효과 아님 |

- 해당 추가 공격 목표 Lv5. 비용이 크면 하위 레벨 비교. 필수 최소 없음.
- 적용 자격: 무기 상태이상이 일치하거나 슬래시액스 독병·마비병. 파티원 상태이상은 가정하지 않는다.
- 폭파는 폭발과 누적 공격 증가를 구분한다. 수면은 별도 지침이 필요하다 (독·마비 규칙 복사 금지).
- 보우건 상태이상 탄의 추천 자격은 별도 설계 (미정).

**미확정 (모델 미구현, 임의 배율·발동 횟수 금지)**
- 축적 사건과 임계치 도달 사건을 같은 확률로 계산하지 않는다. 약33% 축적은 사용자 출발 가정이며 탄·병·포격 포함 일괄 적용 금지.
- 발동 후 초기화('무조건 0')·지속시간·공격별 확률/계수·확률 중첩·후방 유지율 미확인.
- 참고 내성 (나우칼, 비공식): 독2.0 / 마비2.0 / 수면3.0 / 폭파1.3.

## W8. 속성 투자 비용

**근거:** 2026-10-12 사용자 공통 지침. 속성 강화·경지를 고정 추천하지 않고 고룡 버프·혼합과 비교한다.

| 조건 | 판단 |
| --- | --- |
| 무기·스타일 필수 조건 | 먼저 확보 (집중·록온·장전/반동·가드 등) |
| 높은 자체 속성치 | 강화·파라미터 반영 후 해당 고룡 속성% 버프 효율 검토 (사용자 언급: 번개·용·물·얼음) |
| 속성 강화를 거의 확보 못함 | 고정값 스킬 다수보다 적은 고룡 투자가 클 수 있음 (W7 함께) |
| 필수 장비에서 속성 강화·경지 일부 확보 | 소량 추가로 Lv5·경지를 완성하는 안이 유리할 수 있음 |
| 최종 비교 | 추가 장비·연성 비용, 실제 속성 증가·점수, 포기하는 유효 스킬 |

- 고룡3·속성 강화5·경지 모두 강제하지 않는다. 고룡/고정/혼합 모두 비교한다. 고룡 부위는 다른 유효 스킬을 합친 교체 이득으로 본다.
- 예시 (사용자, 확정 수치 아님): 속성 강화5+경지1~2 = 6~7 스킬 레벨로 +700~900 / 고룡 버프3 = 속성+25%.
- 스킬 레벨 합 ≠ 장비 부위 수·연성 칸 수. 실제 추가 비용으로 판단한다.
