# 빌드 컨셉

빌드의 뼈대가 되는 방향(컨셉)과 그 판단 규칙. 정비: 2026-10-16 (기존 `WEAPON_SETTING_GUIDE.md`의 W1·W2·W4·W8을 옮김).

- 문서 지도: 무기·스타일 [WEAPONS.md](WEAPONS.md) / 스킬 [SKILLS.md](SKILLS.md) / 로직·탐색 [AUTO_BUILD.md](AUTO_BUILD.md)

## 빌드를 짜는 순서 (사용자 설명, 2026-10-16)

1. **컨셉 결정:** 빌드의 메인 방향을 먼저 정한다. 이것이 세팅 제안이다.
2. **뼈대 세팅:** 컨셉의 뼈대 스킬은 반드시 들어간다. 레벨과 부위는 선택한다.
   - 뼈대 최소만 가져가고 나머지 스킬을 더 챙기는 안 / 컨셉에 필요한 최대 아웃풋을 내고 나머지를 챙기는 안.
3. **기회비용으로 레벨·부위 결정:** 컨셉을 무너뜨리지 않는 범위에서, 뼈대 스킬을 다른 부위로 옮겼을 때 빈 자리에 더 도움이 되는 스킬이 오면 옮긴다. ([AUTO_BUILD.md A0](AUTO_BUILD.md#a0-기회비용을-고려한-장비-선택))

## 메타 탐색 (사용자 설명, 2026-10-19)

자동빌드 기본 화면은 메타 단위로 빌드를 보여준다. 화면·탐색 구현은 [AUTO_BUILD.md A1-1](AUTO_BUILD.md#a1-1-메타-화면-현재-기본).

- **메타 = 메타 주축 스킬 + 수단** (2026-10-19 '뼈대'에서 이름 변경). 메타 주축 스킬은 핵심 스킬 하나(변형 회심 메타는 약점 특효 포함)를 **Lv4 이상** 확보한다 (예외: 흉회심 메타는 1·3·5, W2 / 속성 메타는 아래). 스킬 최대 레벨이 4보다 낮으면 최대 레벨. 나머지 칸(수단)은 점수가 오르는 스킬로 채우며 레벨을 강제하지 않는다.
- **메타 후보:** 세팅 제안(A2 투자 방향)의 첫 핵심 스킬 메타 + 그 무기에서 켜지는(발동 가정 ON) 공격력·대미지 버프 스킬 하나짜리 메타. 연계·조건부 후보·SP 스킬, 기본 스킬이 꺼지는 경지, 스타일 비권장 스킬은 제외.
- 기존 자동 보충에서 우선순위를 낮춘 스킬도 메타 후보에서는 빼지 않고 예상 점수로 보여준다. 점수가 높으면 추천하고, 원하지 않으면 사용자가 고르지 않는다 (2026-10-19). 예: 겁혈 망토·귀화 망토(돌파구와 세트면 빌드의 축), 멸진룡의 갈망(무심과 함께 쓰는 구성).
- **지침 메타:** 점수가 없어 점수로는 절대 추천되지 않지만 운용상 중요한 스킬은 운용 규칙 표의 '지침 메타' 칸에 적는다. 메타 후보에 항상 보이고 처음부터 선택된다 (예: 차지액스 도끼 강화 속전속결, 상태이상 무기의 추가 공격·축적 위력 (W4), 슬래시액스 기본 변형 공격 강화 (2026-10-20, 역회심 무기 제외 2026-10-24)). 지침 메타가 투자 방향의 첫 핵심과 같으면 그 방향의 메타 주축(예: 변형 회심의 약점 특효)과 투자 후보를 이어받는다.
- 메타마다 독립 탐색한다. 메타끼리 점수로 하나를 고르지 않고 사용자가 고른다 (최대 4개, 많을수록 오래 걸림).
- '점수만(메타 없음)' 행은 두지 않는다.
- 운용 규칙의 필수 스킬은 모든 메타에 그 레벨로 이미 들어가므로 단일 스킬 메타(Lv4+)로 내지 않는다 (예: 해머 임팩트 크레이터 비연 1, 2026-10-22).
- **속성 메타 (2026-10-23 사용자):** 경지는 속성 강화 5가 조건이므로 경지 메타는 속성 강화 5 + 경지 1~2 (가능하면 2, 1/2는 점수로 결정). 자리가 있으면 하이 차지도 점수로 더한다. 하이 차지는 Lv2 이상만 쓰고(1은 안 씀) '하이 차지' 메타로 따로 둔다. 체력 증강은 후보로만 두어 더 좋은 스킬이 있으면 올리지 않는다. 하이 차지 Lv2를 만들 수 없는 속성은 하이 차지 메타를 내지 않는다 (물은 쇼군기자미 머리 1뿐이었으나 아마츠마가즈치 다리 2로 가능, 2026-10-23).
- **메타 종류 (2026-10-23 사용자):** 스킬 메타(기본, 위 규칙) / 컨셉 메타([컨셉 일람](#컨셉-일람-2026-10-23-사용자)) 중 하나만 보여준다.

## 컨셉 일람 (2026-10-23 사용자)

**컨셉 메타:** 점수로는 나오지 않는, 유저들이 만든 특수 세팅(예: 대량발생 이벤트의 8성 차원변이 한방컷 세팅). 컨셉 스킬을 정한 레벨로 확보한 뒤 나머지 칸은 대미지 점수로 채운다 (클리어는 해야 하므로). 메타 화면 ① 무기 설정의 '메타 종류'에서 스킬 메타(기본)와 컨셉 메타 중 하나만 보여준다. 컨셉 메타를 고르면 스킬 메타는 보이지 않고, 그 무기·스타일·탄에 맞는 컨셉 메타만 예상 점수순으로 보인다.

- 레벨 범위(`a~b`)는 점수로 정한다. 점수 없는 컨셉 스킬(파괴왕【특수 스킬】·특수 스킬 위력 상승)은 확보만 하고 점수에 넣지 않는다 (특수 스킬 위력 상승은 SP 스킬이라 OFF, 켜면 +60%가 모든 공격에 붙어 과대).
- 컨셉 스킬은 결과 카드에서 강조하고 흐리게 하지 않는다.
- 실행 로직은 `auto-build-meta.js`의 `AB_CONCEPTS`이며 `tools/auto-build-rules-test.js`가 이 표와 대조한다.

## W1. 회심 보유 무기

**조건 (2026-10-18 사용자, 이전 '자체 회심 20~30% 이상' 기준을 대체):** 회심 세팅 여부는 무기 기본 회심이 아니라 **사용자의 파라미터 선택**으로 판단한다.

- 스타일 강화 파라미터에 회심 +10% 3개를 투자했다면 "이번 세팅은 회심"이라는 의지로 본다 → 기본 회심이 0%라도 회심 방향을 제안한다.
- 기본 회심이 20~30%여도 파라미터를 속성·공격으로 찍었다면 기본 회심은 추가 대미지 정도로만 보고 회심 방향을 잡지 않는다.
- **예외 (변형 공격 강화 중심 무기):** 무기 특성·운용상 변형 공격 강화가 적용되고 빌드의 중심 스킬인 무기는 변형 공격 강화로 회심 80%를 이미 확보하므로, 회심 파라미터 없이 속성 파라미터 3개를 찍는 경우가 있다. 이때는 간파·약점 특효를 1~2개(주로 약점 특효 Lv1 = 회심 20%) 넣어 회심 100%를 맞추는 안을 제안한다.
- **스타일강화를 적용하지 않은 무기 (파라미터 없음):** 기본 회심이 20% 이상이면서 무기 자체 스킬이 회심 관련이거나, 기본 회심이 30% 이상이면 회심 세팅을 고려한다 (2026-10-18 사용자).
- 스타일 레벨업 진행 중(스타일은 바꿨지만 파라미터를 다 찍지 않은 상태)은 따로 고려하지 않는다. 사용자는 최종 결과를 기준으로 세팅한다.
- 회심 관련 무기 스킬: 간파 · 약점 특효 · 슈퍼회심 · 회심격【속성】 · 힘의 해방 (2026-10-18 사용자).
- 파라미터는 특별한 경우가 아니면 3개를 같은 종류로 맞춘다 (빌드 효율). 회심 의지는 회심 3개 단위로만 본다.
- 역회심 무기의 흉회심 방향(W2)은 파라미터와 별개로 유지한다.
- **구현 (2026-10-18):** `abContext`의 `critIntent`(회심 방향), `morph`(무기 특성 '변형' 있음 → 변형 회심 방향을 첫 추천, 약점 특효 레벨은 회심 100%까지 모자란 만큼 자동 계산). 상태이상 무기·흉회심 무기는 기존처럼 해당 방향이 우선한다.

| 조건 | 검토 방향 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 + 속성 무기 | 회심격【속성】·추가 회심 투자 | 회심 전용 효과 활용. 속성 투자 대안도 유지 |
| 속성 파라미터3 | 속성 중심, 회심은 보조 | 사용자 파라미터를 바꾸지 않음 |
| 일반 속성 없는 물리 무기 + 공격 파라미터3 | 물리 중심 | 상태이상 축적치를 속성 피해로 합산하지 않음 |
| 적은 장비로 높은 회심 확보 가능 | 슈퍼회심 투자 비교 | 필수 조합 아님. 자동 보충은 변형 회심 방향 또는 힘의 해방을 직접 넣었을 때만 |
| 회심 파라미터3 + 자체 회심 | 공격 증강【회심】도 비교 | 회심격 방향만 고정하지 않음 |

- **회심 80%는 필수도 목표도 아니다** (2026-10-14 확정). 자체 회심은 투자를 검토할 근거이며, 추가 회심이 없는 안도 비교한다.
- 회심 기대확률 상한 100%. 100% 확보도 비용과 비교한다.
- 간파 Lv1·약점 특효 Lv1이 가장 효율이 좋다. 슬롯이 2개쯤 비면 둘을 1레벨씩 넣는다. 약점 특효는 록온으로 약점 부위를 노리기 쉬워 간파와 동급으로 본다 (2026-10-17 사용자).
- 슈퍼회심: 기본 1.25 → Lv5 1.5. 회심이 100%에서 멀수록 효율이 떨어져 많이 쓰지 않는다. 변형 공격 강화처럼 높은 회심을 보장하는 스킬이 있을 때, 또는 힘의 해방 발동 조건을 맞출 때 함께 검토한다 (2026-10-17 사용자).
- 변형 공격 강화의 회심+80%는 **해당 공격에만** 적용 (예: 기본20%+80% → 그 공격 100%, 절약한 장비를 슈퍼회심에). 전체 공격의 상시 회심으로 보지 않는다. 차지액스도 대상이지만 같은 운용 비율을 가정하지 않는다. 점수는 변형 공격 비중을 발동률 10%로 반영한 기대값 (SKILLS.md 발동률, 2026-10-20). 점수도 변형 공격 타격을 발동률 비중으로 따로 계산해 그 타격만 회심 100%로 보고, 나머지 공격은 남은 회심으로 계산한다 (2026-10-25 사용자, SKILLS 발동률).

| 후보 | 강화 후 자체50%는 유력한 검토 사례. 50%를 장착 임계값으로 쓰지 않음. 셀레기오스 머리도 근거 사례일 뿐 강제 장착 아님 |

## W2. 기본 역회심 무기

**조건:** 파라미터 변경 전 자체 회심이 음수. 기본 방향은 흉회심 보완, 사용자 선택 우선.

| 조건·방향 | 규칙 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 | 흉회심 방향·자동 연성 보충 제외 | 최종 회심이 음수여도 역회심 감소 의도로 해석 |
| 흉회심 Lv1 저투자 | 나머지 장비를 다른 효과에 | 손실을 거의 보완 (정확히 1배는 아님) |
| 흉회심 Lv3 균형 / Lv5 고점 | 서로 다른 투자안으로 비교 | 모든 역회심 무기에 Lv5 강제 금지 |
| 빠른·다타수 무기 (쌍검 등) | 저투자(Lv1)가 보통이지만 Lv3·Lv5 방향도 비교 후보로 둔다 (쌍검 기본 2026-10-25·28 사용자) | 작은 대미지를 여러 번 넣으면 큰 수의 법칙으로 흉회심이 기대값에 수렴한다. 흉회심 5를 챙겨도 그 기대값을 넘지 못하고, 연격 등 그보다 나은 세팅이 많다. 한방 무기(대검·해머)는 메인 타격에 흉회심이 터지면 전체 대미지가 크게 오르는 것과 다르다 |
| 느린·한방 무기 (대검 등) | Lv5 한방 고점 방향 우대 검토 | 사용자 선호. 평균 점수에 보너스는 없음 |
| 전심전력 | 낮은 우선순위 비교 후보 | 금지 아님. 실제 점수가 좋으면 채택 |

- 흉회심 1/3/5 방향은 **해당 레벨까지의 투자 비교**다. 최소0에서 시작하고 미채용도 허용한다. 직접 지정한 최소는 유지한다.
- **메타 (2026-10-21):** 흉회심 메타는 Lv4 규칙 대신 방향의 레벨(저투자 1 / 균형 3 / 고점 5)을 메타 주축으로 쓴다. 역회심 무기(기본 회심 음수, 3회심 제외)는 흉회심 메타가 아닌 메타에서도 흉회심을 보충 후보로 둔다 (흉회심만 있는 장비·흉회심 연성도 검토).
- 무기·겸용 장비에 붙은 흉회심은 보존하고 실제 계산한다. 3회심 선택으로 무기·파라미터를 바꾸지 않는다.
- 전심전력: 공격 증가와 회심 감소를 함께 계산. 늘어난 역회심 중 30%만 흉회심, 70%는 0.75배이므로 순수 버프가 아니다. 흉회심 필수 묶음 아님.

**기대값** (r = 최종 역회심 확률, 상한100%, 흉회심 자체 감소 포함)
- 흉회심 없음: 1 − 0.25r / 있음: (1 − r) + 0.3r × 흉회심 배율 + 0.7r × 0.75
- 기본 −30% 예: 없음 0.925 / Lv1(−10%, ×1.5) 0.99 / Lv3(−20%, ×2) 1.0625 / Lv5(−30%, ×2.5) 1.165. Lv5의 250%를 전체 2.5배로 해석하지 않는다.

## W4. 상태이상 무기

**방향:** 축적으로 발동 기회를 만들고, 발동 이점을 실제 피해로 연결한다. 10성의 높은 체력에서는 독 자체 피해만으로 부족하므로 해당 추가 공격을 중요하게 본다 (사용자 판단, 공식 필수 아님).

| 스킬 | 역할 | 기준 |
| --- | --- | --- |
| 독·마비·수면·폭파 공격 강화 | 축적 시 누적량 증가 | 축적 확률 증가와 구분 |
| 기습 상태 이상 | 후방 조건 축적 확률 증가 | 낮은 우선순위. **예외: 건랜스 블래스트 대시** (후방 확보 쉬움) |
| 하룡의 독 안개 / 염왕룡의 폭발가루 | 위치 조건 없는 축적 확률 증가 | 모든 고룡 효과로 일반화 금지 |
| 추가 공격【폭파】 | 축적 확률 + 폭파마다 공격력 증가(최대10회) | 독·마비 지속 피해와 구분 |
| 상태 이상 축적 시 위력 UP | 축적이 발생한 그 타격의 피해 증가 | 축적 확률 증가·최종 발동 순간 효과가 아님 |
| 추가 공격【독】·【마비】 | 해당 상태 몬스터에게 피해 증가 | 상시 효과 아님 → 유지율로 기대값 (아래) |

- 해당 추가 공격 목표 Lv5. 비용이 크면 하위 레벨 비교. 필수 최소 없음.
- **지침 메타 (2026-10-19 사용자):** 상태이상 무기는 해당 추가 공격(수면은 없음)과 상태 이상 축적 시 위력 UP을 지침 메타로 둔다. 발동률이 짐작 수치라 점수가 실제보다 낮을 수 있으므로 점수 순위와 무관하게 항상 보이고 처음부터 선택된다. 추가 공격 메타는 상태이상 투자 방향(하룡·염왕룡 등)을 이어받는다 (`abStatusMetas`).
- 적용 자격: 무기 상태이상이 일치하거나 슬래시액스 독병·마비병. 파티원 상태이상은 가정하지 않는다.
- 폭파는 폭발과 누적 공격 증가를 구분한다. 수면은 별도 지침이 필요하다 (독·마비 규칙 복사 금지).
- 보우건 상태이상 탄의 추천 자격은 별도 설계 (미정).

**점수 반영 (2026-10-19 사용자 확정, [나우칼](https://mhnowcalc.com/calc/build_editor_simple.php?lang=ko) 기본값):** 조건 체크 없이 발동률을 곱한 기대값. 발동률 값은 [SKILLS.md 발동률](SKILLS.md#발동률) 표 한 곳에서 관리한다 (2026-10-20 모든 조건부 스킬로 확장). 독·마비·축적 위력은 대미지 가산(F)과 따로 곱하는 상태 이상 보정(S, 나우칼 ⑪)에 곱한다.

| 스킬 | 점수 | 근거 |
| --- | --- | --- |
| 추가 공격【독】·【마비】 | 효과 × 27% / 20% (상태 유지율) → S | 나우칼 빌드 편집기 기본 발동률 |
| 추가 공격【폭파】 | 공격력 증가 × 10% (폭파 1회분) + 축적 확률 가산 | 나우칼: 폭파 1회당 10%, 10회면 100% |
| 상태 이상 축적 시 위력 UP | 효과 × 축적 확률 → S | 축적이 발생한 타격만 강화 |
| 하룡의 독 안개 / 염왕룡의 폭발가루 | 축적 확률 가산 (+35/70/100) | 대미지 직접 없음, 축적 위력을 통해 반영 |

- 축적 확률 = (100 + 가산) ÷ 3, 최대 100% ([나우칼 상태 이상 발동률](https://mhnowcalc.com/calc/ailment_activation_rate.php?lang=ko), 정면 기준). 가산: 하룡(독)·염왕룡(폭파) Lv1~3 +35/70/100, 추가 공격【폭파】 Lv1~5 +20~100. 기습【상태 이상】(후방 Lv1~5 +20/65/110/155/200)은 점수에 넣지 않는다.
- 같은 스킬이 여러 개면 S에서 서로 곱한다.

**미확정 (모델 미구현)**
- **독 지속 피해 (보류, 2026-10-19):** 독 1회 = 몬스터 최대 체력 10% (사용자). 하룡·독속성 강화는 독 발동 횟수를 늘려 대미지 가치가 있다. 설계 초안: 총 축적 = 독 수치 × K × 축적 확률 (K = 타수 × 무기 보정, 무기 보정이 타수의 역수라 무기 공통), 발동 횟수 = log₂(1 + 총 축적 ÷ ★10 중앙값 내성 6,147), 점수 × 1 ÷ (1 − 10% × 횟수). K 미정. 이때 추가 공격【독】 유지율은 27% 고정 (사용자).
- 마비·수면·폭파의 발동 효과는 축적 위력과 엮여 독과 계산이 다르다. 별도 지침 필요.
- 축적치 = 상태이상 수치 × 무기 보정 (해머 2.0, 대검 3.5, 태도 1.8, 한손검 1.4, 쌍검 0.8, 랜스·건랜스 1.5, 차지액스 1.6, 슬래시액스 검·도끼 1.2/병 0.4, 활 1.1, [나우칼 연구소](https://mhnowcalc.com/ja/ailment/)). 발동마다 내성 × 독2.0 / 마비2.0 / 수면3.0 / 폭파1.3. 몬스터별 확정 내성은 [나우칼 확정 내성 목록](https://mhnowcalc.com/calc/fixed_resistance_matrix.php?lang=ko) (★10 독 중앙값 6,147).

## W8. 속성 투자 비용

**근거:** 2026-10-12 사용자 공통 지침. 속성 강화·경지를 고정 추천하지 않고 고룡 버프·혼합과 비교한다.

| 조건 | 판단 |
| --- | --- |
| 무기·스타일 필수 조건 | 먼저 확보 (집중·록온·장전/반동·가드 등) |
| 높은 자체 속성치 | 강화·파라미터 반영 후 해당 고룡 속성% 버프 효율 검토 (사용자 언급: 번개·용·물·얼음) |
| 속성 강화를 거의 확보 못함 | 고정값 스킬 다수보다 적은 고룡 투자가 클 수 있음 (W7 함께) |
| 필수 장비에서 속성 강화·경지 일부 확보 | 소량 추가로 Lv5·경지를 완성하는 안이 유리할 수 있음 |
| 최종 비교 | 추가 장비·연성 비용, 실제 속성 증가·점수, 포기하는 유효 스킬 |

- 고룡3·속성 강화5·경지 모두 강제하지 않는다. 고룡/고정/혼합 모두 비교한다. 고룡 부위는 다른 유효 스킬을 합친 교체 이득으로 본다.
- 예시 (사용자, 확정 수치 아님): 속성 강화5+경지1~2 = 6~7 스킬 레벨로 +700~900 / 고룡 버프3 = 속성+25%.
- 스킬 레벨 합 ≠ 장비 부위 수·연성 칸 수. 실제 추가 비용으로 판단한다.
