# 자동빌드 지침 적용 검수

검수: 2026-10-13. 커밋·푸시 미실행. 사용자 운용 지침과 확인된 스킬 설명을 추천 기준으로 연결하며 실제 DPS·전역 최적 빌드를 보장하지 않는다.

## 적용 내용

| 기준 | 연결된 동작 |
| --- | --- |
| 공통 | 회심/역회심·상태이상·레벨 효율·버프1~8순위·장비 기본 스킬·연성 재사용/대체 비용 비교 |
| 속성 | 고룡/고정값/혼합 방향과 실제 추가 속성·투입 레벨·장비/슬롯 비용 비교. 경지 강제 투자 제거 |
| 랜스 | 기본 가드 성능2→3 및 권장 불퇴전/공격적인 방어. 저스트가드·실드태클의 별도 최소/비권장 유지 |
| 한손검 | 기본 가드/저스트러시 가드5, 파고들어베기 절단·다타수, 기본 폴배시의 저스트 교격 조건부 예외 |
| 대검 | 기본/격앙참의 차지 마스터 또는 저스트 모으기 해방·차지 스톡 권장. 수류베기의 상태이상/역회심 투자 예외 |
| 보우건 | 탄별 최소 장전/반동 및 스타일 대체·회피 장전/SP 조건. 사용자 선호 기준 탄의 적용 스킬·회심 제한, 속성 파생 계열 포함 |
| 범위 보완 | 무관한 무기의 포술, 운용 근거 없는 공중/모으기/가드 버프를 자동 점수에서 제외. 상태이상 축적 수치를 직접 피해에 합산하지 않음 |
| 가져오기 | 조건 체크·폴배시 운용·비교 탄 선택 보존. 기존 저장 빌드에 새 기준을 임의 지정하지 않음 |

개별 운용 지침이 없는 무기/스타일은 공통 스펙·효과 적합성 기준을 적용한다. 미제공 플레이 방식·새 필수 레벨은 만들지 않는다. 상세 기준은 [무기 지침](WEAPON_SETTING_GUIDE.md), [보우건 지침](BOWGUN_HANDLING.md), [자동빌드 기준](AUTO_BUILD.md).

## 실제 탐색 결과

| 항목 | 결과 |
| --- | --- |
| 소재·무기군 기본 설정 | 751개 모두 실제 탐색 |
| 지원 변경스타일·기본 폴배시 포함 | 총1,347설정 |
| 유효 후보 생성 | 1,347설정 |
| 코드 오류 / 후보 없음 / 시간 제한 | 각각0건 |
| 탐색한 부분 방어구 조합 | 합계8,455,383개 |
| 검사한 연성 구성 | 합계541,182개 |

동일 방어구의 연성 대안은 서로 다른 구성으로 검사한다. 위 조합 수는 전역의 고유 완성 빌드 수가 아니다.

검수 조건: 각 설정의 첫 추천 방향·연성ON·근접 록온ON·운용 기준ON·강화OFF. 모든 핵심 스킬·정렬·강화/파라미터 조합의 전수 검수는 아니다. 별도 회귀검수로 타마미츠네14무기군의 강화20+3회심, 대표 역회심/상태이상/랜스 방향, 보우건 반복/SP 연계를 확인했다.

각 유효 후보에서 확정 최소/회심 요구·실제 슬롯 수·유한 점수·SP 위력OFF를 검사했다. 정렬 결과는 최대5개의 서로 다른 방어구 조합이며 가져오기/공유 파싱 후 점수가 일치함을 확인했다. 실제 추천 함수와 현재 데이터로 실행했고 DOM 출력만 대체했다.

## 자료·검수 한계

- 최소 반동/장전 자료 미확인5종: 리오레이아·리오레우스 희소종·오도가론 아종 라이트, 마가이마가도·뼈 헤비. 이 설정에서도 탐색은 실행했지만 미확인 최소치를 검증했다고 취급하지 않는다. 유사 무기의 수치를 복사하지 않았으며 화면에 미확인 안내를 유지한다.
- 보우건 점수는 명시된 비교 기준 탄에 적용되는 스킬의 상대 점수다. 실제 탄별 피해·철갑 착탄 초타·사격 비중·전체 탄 순환 DPS는 계산하지 않는다.
- 상태이상 평균 축적 확률·임계치·발동 횟수·유지율, 공격별 모션·육질·가드 후 탄 강화 등 미확정 모델은 만들지 않았다. 폴배시는 저스트 회피 성공 후 공격의 조건부 비교다.
- 실제 브라우저·모바일 UI/실기 검수는 이번 결과에 포함하지 않는다. 화면 렌더링 코드 및 계산/공유 검수와 구분한다.
