# 스킬 사전

빌드 로직이 스킬을 어떻게 이해하는지 정리하는 기준표. **초안 (2026-10-16 자동 생성, 사용자 검토 전).**

| 칼럼 | 뜻 |
| --- | --- |
| 공식 효과 | 공식 스킬 페이지의 최대 레벨 설명 (레벨별 수치는 `skill-desc.js` 원본) |
| 계산 | 현재 점수 계산 반영 상태. 상시 / 조건부 / 미반영(점수에 안 들어감) |
| **기본 가정** | 자동빌드가 기본으로 쓰는 발동 여부. 상시 / ON / OFF / 조건부 ON (무기 동작·선행 스킬이 맞을 때만) / **조건부 후보** (기본은 넣지 않고, 메모의 조건에 맞는 무기·빌드에서만 비교 후보로 넣음. 예: 앙심 — 맞고 버티면 발동은 되지만 일부러 맞으며 쓰지 않으므로 가드·태클 칩 대미지 운용에서만). **발동률은 계산하지 않는다** |
| 분류 | 효과 종류. 컨셉([CONCEPTS.md](CONCEPTS.md))의 뼈대·관련 스킬을 정하는 근거 |
| **액션 조건** | 발동에 필요한 무기 동작. [무기 특성](WEAPONS.md#무기-특성)과 대조해 **해당 동작이 '없음'인 무기·스타일에서는 제외**한다 |
| **상황 조건** | 무기와 무관한 발동 상황. 무기로 거르지 않고 컨셉·운용 가이드·연계 스킬로 판단한다 |
| 연관 | 다른 스킬을 켜거나 선행 조건이 되는 관계 (사용자 설명으로 알려진 것만) |
| 비고 / 메모 | 자동 비고 / 사용자 운용 지식 (비어 있으면 검토 전) |

**액션 조건 코드값:** 모으기 · 가드 · 태클 · 카운터 · 공중 · 저스트 회피 · 회피 · 탄·화살 · 변형 · 포격·병 · 강화 상태 · 특수 스킬

- **기본 가정 원칙 (2026-10-17 사용자 확정):** 몬스터·전투 흐름에 따라 달라지는 조건(포효, 부위 파괴, 체력 최대, 피격 등)은 발동률을 정할 수 없으므로 **ON**으로 계산하고, 실제 발동 여부는 사용자가 판단해 끈다. 플레이어가 일부러 만들어야 하는 상황인 불굴(부활)·재난대처능력(저체력)·그룹 사냥 강화는 **OFF**. 실행 로직 반영은 예정 (현재는 조건부 전부 ON).
- **SKILLS.md는 이제 직접 편집한다** (초기 자동 생성 이후 사용자 검토 내용이 들어가므로 재생성하지 않는다).
- 조건 칼럼은 설명 문장 규칙으로 채운 초안이다. 검토 후 코드 데이터와 1:1로 맞추고 테스트로 대조한다 (예정). **현재 실행 로직은 아직 이 칼럼을 쓰지 않는다.**

## 확인 필요 (검토 시 우선)

- **연계 스킬:** 견인불발·거품의 춤·겁혈 망토·귀화 망토가 돌파구를 켜는 관계, 파괴왕→추격 관계를 점수에 어떻게 반영할지 (현재 돌파구·추격은 항상 발동 가정, 연계 스킬은 효과 없음 처리).
- **회심격【속성】:** 사용자 설명상 '퍼센트 속성치'를 올리는 방법(고룡 속성 버프와 같은 묶음). 자동 분류는 회심 → 어느 쪽으로 볼지 확인.
- **집중:** 모으기 단축 + 일부 무기 게이지 상승. 모으기가 없는 무기·스타일에서도 게이지 효과가 있으므로 액션 조건 하나로 제외하면 안 되는 예외.
- **분류 경계:** 공격력/속성/대미지 % 와 고정값 구분이 컨셉(절대 속성치 / 퍼센트 속성치 / 전체 대미지 %)과 맞는지.
