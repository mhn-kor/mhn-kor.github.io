| 칼럼 | 뜻 |
| --- | --- |
| 공식 효과 | 공식 스킬 페이지의 최대 레벨 설명 (레벨별 수치는 `skill-desc.js` 원본) |
| 계산 | 현재 점수 계산 반영 상태. 상시 / 조건부 / 미반영(점수에 안 들어감) |

| 분류 | 효과 종류. 컨셉([CONCEPTS.md](CONCEPTS.md))의 뼈대·관련 스킬을 정하는 근거 |
| **액션 조건** | 발동에 필요한 무기 동작. [무기 특성](WEAPONS.md#무기-특성)과 대조해 **해당 동작이 '없음'인 무기·스타일에서는 제외**한다 |
| **상황 조건** | 무기와 무관한 발동 상황. 무기로 거르지 않고 컨셉·운용 가이드·연계 스킬로 판단한다 |
| 연관 | 다른 스킬을 켜거나 선행 조건이 되는 관계 (사용자 설명으로 알려진 것만) |
| 비고 / 메모 | 자동 비고 / 사용자 운용 지식 (비어 있으면 검토 전) |

**액션 조건 코드값:** 모으기 · 가드 · 태클 · 카운터 · 공중 · 저스트 회피 · 회피 · 탄·화살 · 변형 · 포격·병 · 강화 상태 · 특수 스킬 · 가드·카운터 보유 · 연속 타격 · 후방
**상황 조건 코드값:** 체력 최대 · 저체력 · 남은 체력 비례 · 포효 · 부위 파괴 후 · 파괴 가능 부위 · 헌터 상태이상 · 헌터 상태이상 생성 · 몬스터 상태이상 · 무기 상태이상 축적 · 약점 · 후방 · 그룹 사냥 · 피격 · 부활 · 연속 명중 · 액션 반복 · 게이지 상태 · 특수 스킬 사용 · 시간 경과 · 회심 발생 · 특정 조건 · 선행 스킬

- **기본 가정 원칙 (2026-10-17 사용자 확정):** 몬스터·전투 흐름에 따라 달라지는 조건(포효, 부위 파괴, 체력 최대, 피격 등)은 발동률을 정할 수 없으므로 **ON**으로 계산하고, 실제 발동 여부는 사용자가 판단해 끈다. 플레이어가 일부러 만들어야 하는 상황인 불굴(부활)·재난대처능력(저체력)·그룹 사냥 강화는 **OFF**. **기본 추천의 플레이 전제 (2026-10-18 사용자):** 물약을 최대한 덜 마시고, 안전하게, 부활 없이 플레이하는 경우를 가정한다 → 체력 최대 유지(완전 충전·하이 차지 만피)는 맞고, 저체력·부활 조건 스킬(재난대처능력·불굴·배수의 진 등)은 중요도가 낮다. 실행 로직은 `auto-build.js`의 `AB_ASSUME`가 이 칸을 따르며 `tools/auto-build-rules-test.js`가 대조한다 (2026-10-18 반영). 기본으로 켠 조건은 자동빌드 화면의 발동 가정 칩으로 끌 수 있다. **컨트롤로 유지하는 조건(연격·기습·불퇴전):** 무기 특성상 켜지는 무기에서는 고수 기준(회피 없이 자리 유지, 연타 유지 등)으로 처음부터 켠 채 계산하고, 중수 이하는 발동 가정 칩으로 끈다 (2026-10-18 사용자, `AB_ASSUME.control`).
- **속성치 계산 순서 (2026-10-17 사용자 확인, 현재 계산식과 일치):** 최종 속성 = ( 무기 속성 × (1 + % 증가 + 회심격[회심 시]) + 고정 가산(속성 강화·경지·하이 차지) ) × 고룡 속성 버프. 회심격·차지 마스터는 무기 자체 속성치에만, 고룡 버프는 모든 가산이 끝난 값에 곱한다.
- **SKILLS.md는 이제 직접 편집한다** (초기 자동 생성 이후 사용자 검토 내용이 들어가므로 재생성하지 않는다).
- 계산 칸의 '미반영'은 초안 생성 시 태도 기준으로만 읽은 값이라, 무기 한정 스킬은 카테고리 검토 때 실제 적용 무기 기준으로 정정한다.
- 조건 칼럼은 설명 문장 규칙으로 채운 초안이다. 검토 후 코드 데이터와 1:1로 맞추고 테스트로 대조한다 (예정). **현재 실행 로직은 아직 이 칼럼을 쓰지 않는다.**
