# 무기 세팅 공통 골격 및 운용 지침

작성: 2026-10-11. 출처는 사용자가 제공한 플레이 경험과 추천 기준이다. 공식 최적 세팅 또는 모든 공격의 상시 효과로 단정하지 않는다. 무기·스타일별 추천을 설계/수정할 때 먼저 검토한다. 현재 문서 저장 단계이며 아래 세팅 방향과 프리셋은 아직 실행 로직에 반영하지 않았다.

## 1. 회심을 보유한 무기의 세팅 방향

주로 기본 회심 20~30%를 가진 무기에서 다음 방향을 비교한다. 회심 수치는 스타일 자동 상승분과 선택 파라미터까지 포함해 다시 판단한다. 20~30%는 대표적인 사례이지 하드 필터가 아니다.

| 방향 | 파라미터 | 기본 골격 |
| --- | --- | --- |
| 회심 중심 | 회심 3개 | 속성무기는 회심격【속성】을 핵심으로 검토하고, 유효 회심률 80~100% 확보를 우선한다. |
| 속성 중심 | 속성 3개 | 속성 피해를 중심으로 구성하고 기존 회심은 보조 효과로 활용한다. |
| 물리 중심 | 공격력 3개 | 속성 피해가 없는 공격력 중심 무기의 대안으로 비교한다. |

해당 무기의 실제 스타일 지원 및 파라미터 선택지를 확인한다. 없는 선택지를 가정하거나 상태이상 축적치를 일반 속성 피해와 동일하게 판단하지 않는다. 사용자가 선택한 파라미터를 임의로 바꾸지 않고, 다른 파라미터 방향은 선택 가능한 비교안으로 제시한다.

회심은 100%일 때 회심 전용 효과를 해당 공격에 온전히 적용할 수 있다. 그러나 회심 확보에 필요한 장비·스킬 투자까지 고려해야 한다. 회심 계열을 무조건 가장 좋은 방향으로 고정하지 않고, 다른 공격·속성 스킬과의 기회비용 및 계산 점수로 비교한다. 기대값 계산의 회심 확률은 100%가 상한이다.

## 2. 슈퍼회심의 우선순위

- 기본 회심 피해 배율 1.25에서 슈퍼회심 Lv5의 1.5로 높이는 효과와, 회심을 확보하는 데 필요한 투자를 함께 평가한다.
- 회심률 확보 스킬 + 슈퍼회심 Lv5를 기본 필수 조합으로 강제하지 않는다. 일반적으로 회심격【속성】과 충분한 회심률 확보보다 우선순위를 낮게 검토한다.
- 적은 장비 투자로 높은 회심을 확보하는 경우 슈퍼회심을 적극적인 후보로 검토한다. 최종 채택은 스킬 제약·운용과 점수 비교에 따른다.
- 사용자 예시: 슬래시액스의 변형 공격 강화는 변형 공격에 한해 최대 회심 +80%를 제공한다. 기본 회심 20%와 합치면 해당 공격은 100% 회심이므로, 회심 확보에 쓰지 않아도 되는 장비 여유를 슈퍼회심에 투자할 수 있다.
- 변형 공격 강화의 회심을 전체 공격의 상시 100%로 취급하지 않는다. 적용 무기·공격 범위와 실제 장비 조합/확보 레벨을 확인한다. 차지액스도 스킬 적용 무기이지만 동일 운용 비율을 임의로 가정하지 않는다.

## 3. 셀레기오스 머리와 공격 증강【회심】

사용자가 언급한 '무기 회심 1%당 공격력 +8' 효과는 사이트에서 `공격 증강【회심】`으로 관리한다. 고정 공격 증가분까지 % 배율을 적용하는 별도 스킬 `공격 활성`과 구분한다.

적용 기준은 무기 자체 회심이며 스타일 강화·회심 파라미터 증가분은 포함한다. 간파·힘의 해방 등 장비/조건부 스킬 회심은 이 효과의 기준에 포함하지 않는다. 기본 역회심이면 공격 증가분은 0이다.

| 조건 | 스킬의 고정 공격 증가분 |
| --- | --- |
| 무기 기본 회심 20% | 20 × 8 = 160 |
| 기본 회심 20% + 회심 파라미터 30% | 50 × 8 = 400 |
| 회심 파라미터 30% 투자에 따른 차이 | 추가 공격력 240 + 회심 확률 증가 효과 |

이 240은 스킬을 실제로 착용했을 때 얻는 증가분이다. 파라미터만으로 공격력 240을 주지는 않는다.

회심 파라미터 3개를 투자한 속성무기는 회심격 방향뿐 아니라 셀레기오스 머리를 통한 물리 공격 증가 방향도 비교한다. 무기 자체 회심 20%보다 강화 후 50%인 경우 해당 장비를 더 유력한 후보로 검토할 수 있다.

**강제 착용 조건은 아니다.** 효과는 기존 공격 증강【회심】 계산으로 평가하고, 다른 머리 장비의 스킬과 비교한다. 임의의 추가 점수·배율을 부여하거나 공격력 증가를 중복 계산하지 않는다. 스타일·필수 스킬을 만족하는 후보에서 이 장비가 탐색 제한 때문에 누락되지 않는지도 검토한다. 50% 역시 검토 예시이지 의무 장착 임계값이 아니다.

## 4. 역회심 무기의 세팅 방향

대상은 파라미터로 회심을 변경하기 전 기본 회심이 음수인 무기다. 기본적으로 역회심을 회심 파라미터로 지우기보다 흉회심으로 보완하는 방향을 검토한다. 다만 사용자의 명시적 파라미터 선택이 우선한다.

### 회심 파라미터 3개의 예외

역회심 무기에서 회심 파라미터 3개를 선택했다면 역회심을 줄이거나 지우려는 의도로 해석한다. 최종 회심이 여전히 음수여도 흉회심 중심 방향을 자동으로 제안하거나 핵심 스킬에 채우지 않는다. 사용자가 선택한 무기를 다른 '흉회심 무기'로 바꾸거나 파라미터를 덮어쓰지 않는다.

이 규칙은 흉회심 중심 세팅의 추천을 제외하는 기준이다. 무기 자체에 흉회심이 붙어 있거나 다른 유용한 스킬과 함께 붙은 방어구의 취급, 사용자가 흉회심을 직접 지정한 경우의 우선권은 실제 구현 전에 확인한다. 스킬의 실제 계산 효과를 임의로 삭제한다는 뜻은 아니다.

### 흉회심 레벨과 기대값

흉회심이 없으면 역회심 발생 공격은 0.75배이며 평균은 `1 − 0.25 × 역회심 확률`이다. 흉회심이 있으면 역회심 발생 중 30%만 흉회심 배율을 적용하고 나머지 70%는 0.75배다.

```text
기대 배율 = (1 − r) + r × 0.3 × 흉회심 배율 + r × 0.7 × 0.75
r = 모든 적용 효과를 반영한 최종 역회심 확률 (최대 100%)
```

흉회심 자체도 회심률을 낮추므로 원래 무기 회심으로 r을 고정하지 않는다. 현재 저장된 스킬 설명 기준으로, 다른 회심 변화가 없는 기본 -30% 무기의 예시는 다음과 같다.

| 흉회심 | 최종 회심 | 기대 배율 |
| --- | --- | --- |
| 없음 | -30% | 0.925 |
| Lv1 (회심 -10%, 흉회심 1.5배) | -40% | 0.99 |
| Lv3 (회심 -20%, 흉회심 2배) | -50% | 1.0625 |
| Lv5 (회심 -30%, 흉회심 2.5배) | -60% | 1.165 |

- Lv1은 역회심 손실을 거의 상쇄하는 저투자 대안이다. 정확히 손실이 없어지는 1배는 아니다. 남은 장비·스킬을 다른 강한 대미지 효과에 투자하는 구성도 비교한다.
- 주로 Lv3 또는 Lv5를 검토하고, Lv5는 한방 고점/공격 특화 방향으로 취급한다. 모든 역회심 무기에 Lv5를 강제하지 않는다.
- Lv5의 250%를 전체 대미지 2.5배로 보지 않는다. 실제 기대값과 다른 스킬에 투자했을 때의 성능을 함께 비교한다.

### 공격 빈도에 따른 추천 선호

- 빠르고 타수가 많은 무기는 장기간 평균이 기대값에 수렴하기 쉬우므로, 흉회심 고레벨에 대한 무조건적인 우대보다 다른 대미지 증가 스킬과의 효율 비교를 우선한다.
- 대검처럼 느리고 한방이 큰 무기는 적은 공격 횟수에서 흉회심이 잘 발동했을 때의 높은 한방을 노리는 방향을 더 유력한 선택지로 제시한다. 이는 사용자의 고점 지향 선호다.
- 공격 횟수가 적으면 기대값보다 높은 결과뿐 아니라 낮은 결과도 나올 수 있다. 동일한 피해·확률 조건에서 공격 속도만으로 평균 배율이 높아지는 것은 아니다. 느린 무기라는 이유로 흉회심의 계산 점수에 임의 배율/보너스를 더하지 않는다.
- '안정적인 평균 점수'와 '한방 고점 지향'을 설명·추천 방향에서 구분한다. 무기별 정확한 우대 가중치는 아직 미확정이다.

### 전심전력

전심전력은 공격력을 올리면서 회심률을 낮춘다. 역회심 확률이 증가하면 그중 30%만 흉회심으로 강화되고 70%는 0.75배로 처리되므로, 역회심 증가 자체를 순수 대미지 버프로 취급하지 않는다.

추천 우선순위는 낮게 두되 후보에서 제외하지 않는다. 다른 유력한 스킬이 부족하거나 실제 공격 증가와 최종 회심을 반영한 점수가 좋은 경우 채택할 수 있다. 흉회심과의 필수 묶음으로 강제하지 않는다. 스킬의 고정 공격 증가와 회심 감소는 기존 계산식으로 평가하고 별도 가중 점수를 중복 부여하지 않는다.

## 5. 스킬 레벨별 투자 효율

스킬의 최소·목표 레벨은 최대 레벨만 보고 정하지 않는다. 실제 스킬 데이터의 레벨별 총효과와 직전 레벨 대비 증가량을 확인하고, 투자 효율이 좋은 구간을 우선 검토한다. 아래 수치는 증가 곡선을 설명하기 위한 예시이며 특정 스킬의 공식 수치를 대체하지 않는다.

- `5 / 10 / 15 / 20 / 25%`: 매 레벨 +5%로 일정하다. Lv2·3·5 등 확보 가능한 레벨을 유연하게 비교한다.
- `10 / 15 / 20 / 30 / 40%`: 레벨별 추가 증가량은 `10 / 5 / 5 / 10 / 10%p`다. Lv1만 확보하는 저투자안과 Lv3 이상 투자해 Lv4·5의 큰 증가 구간까지 노리는 안을 비교한다. Lv3 자체가 최대 효율 구간이거나 모든 유사 스킬의 필수 최소 레벨이라는 뜻은 아니다.
- Lv1의 초기 효과가 높다면 Lv1만 확보하고 남은 장비·연성 슬롯을 다른 스킬에 투자하는 구성도 유력한 후보로 검토한다.
- 초기 효율이 좋은 여러 스킬을 낮은 레벨로 조합하는 '다이소 메타'도 세팅 방향의 하나로 비교한다. 모든 스킬을 최대 레벨로 맞추는 방향만 탐색하지 않는다.

최소 몇 레벨을 확보할지와, 투자한다면 몇 레벨까지 올릴지를 구분한다. 증가량뿐 아니라 필요한 장비·연성 슬롯, 다른 스킬을 포기하는 비용, 적용 공격·발동 조건과 실제 기대 점수도 함께 평가한다. 서로 다른 종류의 효과를 표시 퍼센트만으로 직접 비교하지 않는다.

사용자가 지정한 최소 레벨과 무기·스타일의 필수 조건이 우선이다. 별도 지침이 없는 경우의 `MAX−2 ~ MAX`는 임시 기본 범위이지 모든 스킬에 강제하는 효율 기준이 아니다. 저투자 조합에서도 필수 스킬을 누락하거나 동시에 유지할 수 없는 조건부 효과를 모두 상시 적용하지 않는다. 이 기준은 문서 지침이며 추천 로직의 레벨 범위·탐색 방식 변경은 별도 구현 단계에서 반영한다.

## 6. 상태이상 무기의 세팅 방향

사용자 운용 지침: 상태이상 세팅은 축적 확률·축적량으로 발동 기회를 확보하고, 발동 시 얻는 이점을 실제 피해로 연결하는 구성이 핵심이다. 독 자체 피해만으로 높은 체력의 10성 몬스터를 상대하기에는 부족하다는 사용자 판단에 따라, 해당 상태이상의 추가 공격 스킬을 핵심으로 검토한다. 이는 추천 방향이며 모든 무기의 공식 필수 조건으로 단정하지 않는다.

### 축적과 발동을 구분

- '축적 발생'은 공격이 상태이상 누적치를 더하는 사건이고, '상태이상 발동'은 누적치가 몬스터의 해당 상태이상 임계치에 도달하는 사건이다. 두 사건을 같은 확률로 계산하지 않는다.
- 사용자가 제시한 기본 축적 확률 약 33%는 일반적인 상태이상 무기 공격의 출발 가정으로 기록한다. 정확한 1/3 여부와 공격별 예외는 구현 전 검증한다. 모든 공격에 일괄 적용하지 않으며, 상태이상 탄·병·포격 등의 적용 범위를 별도로 확인한다.
- 축적량은 상태이상 수치와 축적량 증가 스킬뿐 아니라 무기·공격별 보정까지 고려한다. 무기 + 방어구의 표시 수치를 매 타격마다 그대로 누적한다고 가정하지 않는다. 상태이상 수치를 일반 속성 대미지로 직접 더하지 않는다.
- 몬스터·상태이상별 최초 임계치와 재발동 임계치를 구분한다. 사용자 설명의 '발동 후 0으로 초기화'는 초과 축적치 처리·발동 중 재축적·자연 감소 여부를 확인하기 전 확정 계산 규칙으로 만들지 않는다.

조사 참고(2026-10-11): [나우칼 상태이상 기초 메커니즘](https://mhnowcalc.com/en/basic-status-effect-mechanics/)은 무기별 축적 보정, 상태이상 탄의 확정 축적, 조건에 따른 발동 중 재축적을 설명한다. 재발동 내성 배율은 독 2.0 / 마비 2.0 / 수면 3.0 / 폭파 1.3으로 제시한다. 공식 발표 수치로 취급하지 않고 검증용 참고값으로 보관한다. 몬스터별 최초 임계치·상한·반복 적용 방식은 별도 확인해야 하며, 이 배율만으로 모든 몬스터의 재발동을 확정하지 않는다.

### 추천 우선순위와 계산 전 확인

- 해당 상태이상의 추가 공격 스킬은 Lv5를 우선 목표로 검토한다. Lv5 확보 비용이 크면 레벨별 증가량·축적 확률·실제 발동 기회를 비교하여 적정 하위 레벨을 선택한다. 필수 최소 레벨은 아직 지정되지 않았으므로 Lv5를 모든 후보의 강제 자격 조건으로 만들지 않는다.
- 기본 피해, 축적 확률, 축적량, 전투 시간 내 발동 횟수와 발동 중 공격 가능 시간을 함께 평가한다. 폭파는 지속 상태 동안 공격하는 모델이 아니라 폭발과 누적 공격 증가를 구분한다. 수면은 첫 공격 등 별도 운용 지침이 필요하며 독·마비의 추가 공격 규칙을 그대로 확장하지 않는다.
- 기습 상태 이상의 낮은 우선순위 및 블래스트 대시 예외는 사용자 경험에 따른 추천 기준이다. 공식 사용률 자료처럼 표현하거나 다른 유용한 스킬이 붙은 장비까지 배제하지 않는다.
- 기존 무기 상태이상 일치 검사와 슬래시액스 독병·마비병 예외는 유지한다. 상태이상 탄을 가진 보우건의 추천 자격은 무기 표시 속성과 탄종을 구분해 별도 설계한다. 파티원이 거는 상태이상은 현 비교 계산에 임의로 추가하지 않는다.
- 미확정 데이터: 몬스터별 내성·지속 시간·재발동 조건, 공격별 축적 계수/발생 확률, 확률 스킬의 중첩, 후방 유지율, 실제 공격 빈도와 상태이상 중 공격 가능 비율. 검증 전 임의의 상시 배율·발동 횟수로 점수를 부풀리지 않는다.

이번 내용은 지침 저장과 참고자료 확인이며, 상태이상 추천·점수 계산 로직을 변경하지 않는다.

## 7. 랜스 / 저스트가드 스타일

운용 방향: 가드 중심의 공격 특화. 아래 가드 동작 설명은 사용자가 제공한 운용 지식으로 기록한다.

- 타이밍에 맞춘 저스트가드로 몬스터 공격을 받아치고, 방어 스킬보다 공격 스킬에 투자한다.
- 늦은 가드는 착용한 가드 성능 레벨과 관계없이 가드 성능 0으로 처리되어 피해·밀림이 발생한다는 사용자 설명에 따라, 가드 성능을 불필요한 스킬로 분류한다.
- 회피 대신 한자리에서 가드하는 운용이므로 불퇴전을 핵심으로 사용한다. 반사는 가드 시 발생하는 보조 피해 수단이다.

| 순위 | 스킬 | 최소 → 목표 | 평가 |
| --- | --- | --- | --- |
| 1 / 필수 | 불퇴전 | Lv4 → Lv5 | 최소 4 확보 후 5를 우대 |
| 2 / 필수 | 반사 | Lv1 → 스킬 데이터의 최대 레벨 | 점수와 별개로 레벨이 높을수록 우대 |
| 3 / 권장 | 매진 | Lv2 → Lv3 | 불퇴전의 공백을 보완. 목표 3 초과는 우선순위 보상 없음 |
| 비권장 | 가드 성능 | — | 이 스킬 때문에 장비를 우대하지 않음 |

반사는 피해 점수에 임의로 가산하지 않는다. 우선순위 정렬은 반사 레벨을 우대하고, 점수 정렬이라도 최소 Lv1 요구는 유지한다. 매진이나 가드 성능이 다른 유용한 스킬과 함께 붙어 있다고 방어구 자체를 배제하지 않는다.

매진은 불가피한 이동 이후 불퇴전 재발동까지 기다리는 약 10초 구간의 보완 효과로 다룬다. 불퇴전·매진 Lv5를 함께 목표로 강제하지 않는다. 두 최대 효과가 전투 내내 동시에 유지되는 점수를 추천 근거로 쓰지 않는다. 실제 점수 계산에 사용할 구간별 발동률/대표 조건은 아직 미확정이며, 구현 전 확인이 필요하다.

## 8. 랜스 / 실드태클 스타일

운용 방향: 방패를 들고 돌진하며 싸우는 방어 특화 스타일. 공격 특화인 저스트가드와 구분한다. 아래 동작·판정 설명은 사용자가 제공한 운용 지식으로 기록한다.

- 돌진 중 받는 공격은 가드 판정으로 처리된다. 가드 성능이 부족하면 돌진을 유지하지 못하고 피격되므로, 돌진 유지에 필요한 가드 성능 확보를 최우선으로 한다.
- 돌진 중 가드를 활용하므로 반사를 보조 피해 수단으로 권장한다.
- 실드태클 돌진 자체는 캐릭터의 회피 동작으로 취급되지 않아 불퇴전이 해제되지 않는다는 사용자 설명에 따라, 불퇴전을 3순위 후보로 검토한다. 이를 모든 이동·회피에서 불퇴전이 유지된다는 규칙으로 확장하지 않는다.

| 순위 | 스킬 | 판단 기준 |
| --- | --- | --- |
| 1 / 최우선 | 가드 성능 | 몬스터 공격을 가드하며 돌진을 유지하기 위한 핵심 조건 |
| 2 / 권장 | 반사 | 돌진 중 가드에 따른 보조 피해 |
| 3 / 검토 | 불퇴전 | 실드태클 돌진으로 해제되지 않는 특성을 활용 |

각 스킬의 최소·목표 레벨은 아직 미확정이다. 저스트가드의 불퇴전 Lv4~5·반사 최소 Lv1 기준을 실드태클에 자동으로 복사하지 않는다. 특히 가드 성능은 대상 몬스터·공격에 필요한 수준을 확인한 뒤 기준을 정한다. 반사는 기존 지침처럼 메인 피해 점수에 임의로 가산하지 않는다.

저스트가드에서 가드 성능을 비권장으로 취급하는 규칙은 실드태클에 적용하지 않는다. 공통 지침보다 선택한 스타일의 우선순위를 먼저 검토한다. 이번 내용은 지침 저장이며 추천 프리셋·점수 계산 로직은 변경하지 않는다.
