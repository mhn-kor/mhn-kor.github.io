## W1. 회심 보유 무기

**조건:** 강화·파라미터를 반영한 무기 자체 회심 > 0. 20~30%는 대표 사례일 뿐 하드 필터가 아니다.

| 조건 | 검토 방향 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 + 속성 무기 | 회심격【속성】·추가 회심 투자 | 회심 전용 효과 활용. 속성 투자 대안도 유지 |
| 속성 파라미터3 | 속성 중심, 회심은 보조 | 사용자 파라미터를 바꾸지 않음 |
| 일반 속성 없는 물리 무기 + 공격 파라미터3 | 물리 중심 | 상태이상 축적치를 속성 피해로 합산하지 않음 |
| 적은 장비로 높은 회심 확보 가능 | 슈퍼회심 투자 비교 | 필수 조합 아님 |
| 회심 파라미터3 + 자체 회심 | 공격 증강【회심】도 비교 | 회심격 방향만 고정하지 않음 |

- **회심 80%는 필수도 목표도 아니다** (2026-10-14 확정). 자체 회심은 투자를 검토할 근거이며, 추가 회심이 없는 안도 비교한다.
- 회심 기대확률 상한 100%. 100% 확보도 비용과 비교한다.
- 슈퍼회심: 기본 1.25 → Lv5 1.5. 보통 회심격·회심 확보보다 낮게 검토한다.
- 변형 공격 강화의 회심+80%는 **해당 공격에만** 적용 (예: 기본20%+80% → 그 공격 100%, 절약한 장비를 슈퍼회심에). 전체 공격의 상시 회심으로 보지 않는다. 차지액스도 대상이지만 같은 운용 비율을 가정하지 않는다.

### 공격 증강【회심】

| 항목 | 규칙 |
| --- | --- |
| 기준 회심 | 무기 자체 + 스타일 강화 + 회심 파라미터. 간파·힘의 해방 등 장비 회심 제외 |
| 증가분 | 착용 시 기준 회심 1%당 공격력 +8. 음수는 0 |
| 예시 | 자체20% → +160 / 자체20%+파라미터30% → +400 |
| 주의 | 고정 증가분까지 곱하는 '공격 활성'과 다른 스킬. 파라미터만으로 증가분 지급 금지, 중복 보너스 금지 |
| 후보 | 강화 후 자체50%는 유력한 검토 사례. 50%를 장착 임계값으로 쓰지 않음. 셀레기오스 머리도 근거 사례일 뿐 강제 장착 아님 |

## W2. 기본 역회심 무기

**조건:** 파라미터 변경 전 자체 회심이 음수. 기본 방향은 흉회심 보완, 사용자 선택 우선.

| 조건·방향 | 규칙 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3 | 흉회심 방향·자동 연성 보충 제외 | 최종 회심이 음수여도 역회심 감소 의도로 해석 |
| 흉회심 Lv1 저투자 | 나머지 장비를 다른 효과에 | 손실을 거의 보완 (정확히 1배는 아님) |
| 흉회심 Lv3 균형 / Lv5 고점 | 서로 다른 투자안으로 비교 | 모든 역회심 무기에 Lv5 강제 금지 |
| 빠른·다타수 무기 | 다른 대미지 스킬 효율 우선 비교 | 타격이 많을수록 평균 기대값에 수렴 |
| 느린·한방 무기 (대검 등) | Lv5 한방 고점 방향 우대 검토 | 사용자 선호. 평균 점수에 보너스는 없음 |
| 전심전력 | 낮은 우선순위 비교 후보 | 금지 아님. 실제 점수가 좋으면 채택 |

- 흉회심 1/3/5 방향은 **해당 레벨까지의 투자 비교**다. 최소0에서 시작하고 미채용도 허용한다. 직접 지정한 최소는 유지한다.
- 무기·겸용 장비에 붙은 흉회심은 보존하고 실제 계산한다. 3회심 선택으로 무기·파라미터를 바꾸지 않는다.
- 전심전력: 공격 증가와 회심 감소를 함께 계산. 늘어난 역회심 중 30%만 흉회심, 70%는 0.75배이므로 순수 버프가 아니다. 흉회심 필수 묶음 아님.

**기대값** (r = 최종 역회심 확률, 상한100%, 흉회심 자체 감소 포함)
- 흉회심 없음: 1 − 0.25r / 있음: (1 − r) + 0.3r × 흉회심 배율 + 0.7r × 0.75
- 기본 −30% 예: 없음 0.925 / Lv1(−10%, ×1.5) 0.99 / Lv3(−20%, ×2) 1.0625 / Lv5(−30%, ×2.5) 1.165. Lv5의 250%를 전체 2.5배로 해석하지 않는다.

## W3. 스킬 레벨 투자 효율

레벨별 총효과·추가 증가량·장비/연성 비용·발동 조건·기회비용을 함께 비교한다.

| 증가 곡선 예시 | 판단 |
| --- | --- |
| 5/10/15/20/25% | 매 레벨 +5%p. Lv2·3·5 등 유연하게 비교 |
| 10/15/20/30/40% | 추가량 10/5/5/10/10%p. Lv1 저투자와 Lv3 이상 → Lv4·5 투자안 비교 (Lv3 자체를 최적·필수로 단정하지 않음) |
| Lv1 초기 효율이 높음 | 여러 스킬 Lv1 조합('다이소') 검토 |

- 최소와 목표를 분리한다. 별도 지침이 없으면 Lv1~목표를 비교한다 (MAX−2~MAX 고정 범위는 폐기).
- 같은 단위의 단일 효과만 곡선 비교한다. 복합·확률·비수치 효과를 하나의 피해 배율로 환산하지 않는다.
- 예시 수치는 공식 스킬 수치를 대체하지 않는다.

## W4. 상태이상 무기

**방향:** 축적으로 발동 기회를 만들고, 발동 이점을 실제 피해로 연결한다. 10성의 높은 체력에서는 독 자체 피해만으로 부족하므로 해당 추가 공격을 중요하게 본다 (사용자 판단, 공식 필수 아님).

| 스킬 | 역할 | 기준 |
| --- | --- | --- |
| 독·마비·수면·폭파 공격 강화 | 축적 시 누적량 증가 | 축적 확률 증가와 구분 |
| 기습 상태 이상 | 후방 조건 축적 확률 증가 | 낮은 우선순위. **예외: 건랜스 블래스트 대시** (후방 확보 쉬움) |
| 하룡의 독 안개 / 염왕룡의 폭발가루 | 위치 조건 없는 축적 확률 증가 | 모든 고룡 효과로 일반화 금지 |
| 추가 공격【폭파】 | 축적 확률 + 폭파마다 공격력 증가(최대10회) | 독·마비 지속 피해와 구분 |
| 상태 이상 축적 시 위력 UP | 축적이 발생한 그 타격의 피해 증가 | 축적 확률 증가·최종 발동 순간 효과가 아님 |
| 추가 공격【독】·【마비】 | 해당 상태 몬스터에게 피해 증가 | 상태 중 공격 가능 시간 검토. 상시 효과 아님 |

- 해당 추가 공격 목표 Lv5. 비용이 크면 하위 레벨 비교. 필수 최소 없음.
- 적용 자격: 무기 상태이상이 일치하거나 슬래시액스 독병·마비병. 파티원 상태이상은 가정하지 않는다.

## W6. 방어구·연성 우선순위

**근거:** 2026-10-12 사용자 지침. 상위 기준은 [A0](AUTO_BUILD.md#a0-기회비용을-고려한-장비-선택): 아래는 **후보 선별·동률 비교용**이며 최종 판단은 교체·보완 후 전체 구성 비교다.

| 순서 | 기준 | 제한 |
| --- | --- | --- |
| 1 | 운용에 중요한 연성 대체 불가 스킬을 가진 장비 | 무관한 스킬까지 우대하지 않음 |
| 2 | 연성 가능 스킬은 한 부위의 높은 레벨 | 교체 시 필요 연성 칸·다른 부위 기회비용 비교 |
| 3 | 유효 스킬의 레벨 합·효과 | 스킬 종류 수로 평가하지 않음 |
| 4 | 적은 연성 비용으로 대체할 부위는 교체하고 대체 불가 효과 확보 | 특정 부위 고정·2소켓 금지로 해석하지 않음 |

- 유틸(내성·상태이상 속성 강화·귀마개·풍압 등)은 낮은 우선순위. 강화 지속은 무기·스타일에 유효하면 상대적으로 높게 본다.
- 명시된 운용 필수(상태이상 축적, 가드 성능·반동·장전 등)는 낮은 우선순위로 덮어쓰지 않는다.
- 장비 기본 스킬을 먼저 평가하고 연성으로 핵심을 보충한다. 슬롯 수 자체에는 가산점이 없다. 필요한 필수 연성 칸은 확보한다.
- 연성 배치: 같은 기본 스킬이 붙은 부위의 빈 슬롯 우선 → 없으면 다른 부위. 기존 연성은 덮어쓰지 않는다. 재사용성 규칙일 뿐 피해 보너스가 아니다.
- 연성전용 핵심은 명시 최소를 채운 뒤 장비·연성 이득을 비교한다. 남은 칸을 1·2·3순위 MAX로 순서대로 채우지 않는다.
- 예시 (사용자): 에스피나스 추격 갑옷Lv3 / 허리Lv2 → 갑옷 유지·허리Lv2 연성 보충안을 먼저 보되, 다른 갑옷의 더 중요한 효과도 비교한다.

## W7. 버프 종류별 우선순위

**근거:** 2026-10-12 사용자 공통 지침. 순위는 **분류 순서**이며 대미지 배율·가중치가 아니다.

| 순위 | 효과 | 발동 조건 | 방식 |
| --- | --- | --- | --- |
| 1 / 2 | 대미지 버프 | 없음 / 있음 | % |
| 3 / 4 | 공격력·속성 버프 | 없음 / 있음 | % |
| 5 / 6 | 대미지 버프 | 없음 / 있음 | +고정값 |
| 7 / 8 | 공격력·속성 버프 | 없음 / 있음 | +고정값 |

- 적용 가능한 공격 후보끼리 비교할 때 쓴다. 운용 필수·사용자 핵심 순위·무기별 예외가 우선한다.
- 적용 불가·계산 제외 효과를 이 순위로 되살리지 않는다. 점수순 정렬은 실제 점수가 우선이다.
- 회심·복합·체력 의존·회심 비례 효과는 단일 분류에 넣지 않고 기존 계산으로 비교한다. 경지의 장착 레벨 선행조건은 전투 유지 조건이 아니다.

## W8. 속성 투자 비용

**근거:** 2026-10-12 사용자 공통 지침. 속성 강화·경지를 고정 추천하지 않고 고룡 버프·혼합과 비교한다.

- 예시 (사용자, 확정 수치 아님): 속성 강화5+경지1~2 = 6~7 스킬 레벨로 +700~900 / 고룡 버프3 = 속성+25%.

| 속성충전카운터 | 앙갚음 우선 + 일반 근접 투자 | 카운터 성공 시 추가타. 변형 공격 대상 동작이 줄어듦 |

- **상태이상 무기의 축적 (사용자 설명):** 검·도끼 모드의 일반 타격은 축적 확률 약33%. 병이 터지는 타격은 축적 확률 100%지만 누적치는 1/3. 병 발동·병 누적치·일반 타격 확률·최종 발동을 구분한다.
- 비상용검의 '상태이상을 제외하고선'은 위 이유로 상태이상 무기에서는 병 타격으로 축적 기회가 충분하다는 뜻이다. 상태이상 무기는 기본스타일처럼 해당 추가 공격을 우선 검토하고, 그 외 무기는 도끼 중심 일반 투자를 쓴다.
- '반반'을 50% 배율로 환산하지 않는다. 효율이 낮다는 설명을 적용 불가·장비 금지로 바꾸지 않는다. 흉회심 방향에 변형 회심을 강제하지 않는다.
- **확인 필요 (구현 전):** ① 병 누적치의 기준값 (1/3의 기준이 되는 수치) ② 앙갚음 공식 효과·적용 공격 ③ 스타일별 최소/목표 레벨.
