## W1. 회심 보유 무기

**조건:** 강화·파라미터까지 반영한 무기 자체 회심을 사용한다. 기본20~30%는 대표 사례이며 하드 필터가 아니다.

| 선택·조건 | 검토 방향 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3개 + 속성 무기 | 회심격【속성】·추가 회심의 투자 효율 검토 | 회심 전용 효과 활용. 특정 회심률 확보 강제 없음; 속성 투자 대안도 유지 |
| 속성 파라미터3개 | 속성 중심, 기존 회심은 보조 | 사용자가 선택한 파라미터를 바꾸지 않음 |
| 일반 속성 피해 없는 물리 무기 + 공격 파라미터3개 | 물리 중심 | 상태이상 축적치를 일반 속성 피해로 합산하지 않음 |
| 적은 장비로 높은 회심 확보 가능 | 슈퍼회심 투자 비교 | 일반 필수 조합으로 강제하지 않음 |
| 회심 파라미터3개 + 자체 회심 활용 | 공격 증강【회심】 방향도 비교 | 회심격 방향만 고정하지 않음 |

- 회심 기대확률 상한100%. 100%이면 해당 공격의 회심 효과를 온전히 활용하지만 확보 비용까지 비교한다.
- 슈퍼회심: 기본1.25 → Lv5의1.5. 일반적으로 회심격·회심 확보보다 낮게 검토하며 다른 공격·속성 투자와 비교한다.
- 사용자 예시: 슬래시액스 변형 공격 강화의 최대 회심+80%와 기본20%를 합치면 해당 공격은100%. 절약한 장비를 슈퍼회심에 투자할 수 있다.
- 변형 공격 효과를 전체 공격의 상시 회심으로 간주하지 않는다. 차지액스도 적용 무기지만 같은 운용 비율을 가정하지 않는다. 실제 효과·장비·적용 공격 범위는 데이터로 확인한다.
- 없는 스타일·파라미터 선택지를 가정하지 않는다.
- 2026-10-14 사용자 확인·실행 반영: 회심 방향은 자체 회심을 바탕으로 투자를 검토할 만한 방향이지80% 확보 조건이 아니다. 필수80%·고정 목표80%를 모두 두지 않고 전체 구성의 투자 효율로 판단한다.

### 공격 증강【회심】

**근거:** 사용자 지침 + 기존 계산. 셀레기오스 머리 사례는 후보 판단 근거이며 강제 장착 조건이 아니다.

| 항목 | 규칙 |
| --- | --- |
| 기준 회심 | 무기 자체 회심 + 스타일 강화·회심 파라미터. 간파·힘의 해방 등 장비 회심 제외 |
| 증가분 | 해당 스킬 착용 시 유효 기준 회심1%당 공격력+8. 음수는0 |
| 구분 | 고정 증가분까지 %를 곱하는 ‘공격 활성’과 다른 스킬 |
| 예시 | 자체20% → +160 / 자체20%+파라미터30% → +400 / 차이+240 |
| 주의 | 파라미터만으로 +240 지급 금지. 기존 계산과 중복 보너스 금지 |
| 후보 | 강화 후 자체50%는20%보다 유력한 검토 사례. 50%를 의무 장착 임계값으로 사용하지 않음 |

## W2. 기본 역회심 무기

**조건:** 파라미터 변경 전 자체 회심이 음수인 무기. 기본 방향은 흉회심 보완이며 사용자 선택이 우선한다.

| 조건·방향 | 규칙 | 이유·예외 |
| --- | --- | --- |
| 회심 파라미터3개 | 흉회심 중심 방향·자동 연성 보충 제외 | 최종 회심이 음수여도 역회심 감소 의도로 해석 |
| 흉회심 Lv1 저투자 | 나머지 장비를 다른 강한 효과에 투자 | 손실을 거의 보완하지만 정확히1배는 아님 |
| 흉회심 Lv3 균형 / Lv5 고점 | 서로 다른 투자안으로 비교 | 모든 역회심 무기에 Lv5 강제 금지 |
| 빠른·다타수 무기 | 다른 대미지 스킬의 효율 비교 우선 | 많은 타격에서 평균 기대값에 수렴 |
| 느린·한방 무기(대검 등) | Lv5 한방 고점 방향 우대 검토 | 사용자 선호. 기대값보다 높은 결과와 낮은 결과 모두 가능 |
| 전심전력 | 낮은 우선순위 비교 후보 | 금지하지 않음. 다른 스킬이 부족하거나 실제 점수가 좋으면 채택 |

- 3회심 선택으로 무기·파라미터를 임의 교체하지 않는다. 무기 기본/겸용 장비의 흉회심은 보존하며 실제 계산한다. 직접 지정한 흉회심은 사용자 선택을 우선한다.
- 느린 공격이라는 이유로 평균 점수에 보너스를 주지 않는다. 정확한 선호 가중치는 미확정이다.
- 2026-10-14: 자동 흉회심1/3/5 방향은 해당 레벨까지의 투자 비교다. 최소0으로 시작하며 다른 효과가 유리하면 미채용도 허용한다. 직접 지정한 최소는 유지한다.
- 전심전력의 공격 증가·회심 감소를 함께 계산한다. 증가한 역회심 중30%만 흉회심이며70%는0.75배이므로 역회심 증가 자체를 순수 피해 버프로 취급하지 않는다. 흉회심 필수 묶음으로 강제하지 않는다.

### 기대값 참고

r = 모든 회심 변화를 반영한 최종 역회심 확률(상한100%).
- 흉회심 없음: 1 − 0.25 × r
- 흉회심 있음: (1 − r) + r × 0.3 × 흉회심 배율 + r × 0.7 × 0.75
- 흉회심 자체의 회심 감소도 r에 포함한다. Lv5의250%를 전체 피해2.5배로 해석하지 않는다.

기존 스킬 데이터 기준, 기본-30%·다른 회심 변화 없음:

| 흉회심 | 최종 회심 | 기대 배율 |
| --- | --- | --- |
| 없음 | -30% | 0.925 |
| Lv1: 회심-10%, 배율1.5 | -40% | 0.99 |
| Lv3: 회심-20%, 배율2 | -50% | 1.0625 |
| Lv5: 회심-30%, 배율2.5 | -60% | 1.165 |

## W3. 스킬 레벨 투자 효율

**판단:** 레벨별 총효과·추가 증가량·장비/연성 비용·발동 조건·기회비용을 함께 비교한다.

| 증가 곡선 예시 | 판단 |
| --- | --- |
| 5/10/15/20/25% | 매 레벨+5%p. 가능한 Lv2·3·5 등을 유연하게 비교 |
| 10/15/20/30/40% | 추가량10/5/5/10/10%p. Lv1 저투자와 Lv3 이상 확보 후 Lv4·5까지 투자하는 안 비교 |
| Lv1 초기 효율이 높음 | 여러 스킬을 Lv1로 조합하는 ‘다이소’ 대안 검토 |

- 예시는 공식 스킬 수치를 대체하지 않는다. 두 번째 예시의 Lv3 자체를 최고 효율이나 필수 최소로 단정하지 않는다.
- 최소와 목표를 분리한다. MAX−2~MAX 고정 범위는 폐기하며 별도 지침이 없으면 Lv1~목표를 비교한다.
- 사용자 최소·운용 필수 조건은 저투자안에서도 유지한다.
- 같은 단위의 단일 효과만 곡선 비교한다. 복합·확률·비수치 효과나 다른 종류의 %를 하나의 피해 배율로 환산하지 않는다.
- 핵심 우선·점수 우선·Lv1 중심 연성 경로를 비교하되 전역 최적 투자는 보장하지 않는다.

## W4. 상태이상 무기

**방향:** 축적 확률·축적량으로 발동 기회를 확보하고, 발동 이점을 실제 피해로 연결한다. 사용자 판단상10성의 높은 체력에서는 독 자체 피해만으로 부족하므로 해당 추가 공격을 중요하게 검토한다. 공식 필수 세팅으로 단정하지 않는다.

| 스킬군 | 역할 | 추천 기준 |
| --- | --- | --- |
| 독·마비·수면·폭파 공격 강화 | 축적 발생 시 누적량 증가 | 축적 확률 증가와 구분 |
| 기습 상태 이상 | 후방 조건의 축적 확률 증가 | 일반 우선순위 낮음. 후방 확보가 쉬운 건랜스 블래스트 대시는 예외 |
| 오나즈치 독 / 테오테스카토르 폭파 효과 | 위치 조건 없는 해당 축적 확률 증가 | 모든 고룡 효과로 일반화 금지. 실제 레벨·중첩 확인 |
| 추가 공격【폭파】 | 축적 확률 증가 + 폭파 발생마다 공격력 증가(최대10회) | 독·마비의 지속 피해 증가와 구분 |
| 상태 이상 축적 시 위력 UP | 축적이 발생한 해당 타격의 피해 증가 | 축적 확률 증가나 상태이상 최종 발동 순간만의 효과가 아님 |
| 추가 공격【독】·【마비】 | 해당 상태의 몬스터에게 주는 피해 증가 | 발동 중 실제 공격 가능한 시간 검토. 상시 효과로 오인 금지 |

- 해당 추가 공격 목표Lv5. 비용이 크면 증가 곡선·발동 기회를 보고 하위 레벨 비교. 필수 최소는 미지정이다.
- 무기 상태이상 일치 검사와 슬래시액스 독병·마비병 예외를 유지한다. 보우건 상태이상 탄의 추천 자격은 표시 속성과 분리해 별도 설계한다.
- 파티원이 부여하는 상태이상은 현 비교 계산에 가정하지 않는다. 무관한 스킬이 붙은 겸용 방어구 자체는 금지하지 않는다.
- 폭파는 폭발·누적 공격 증가를 구분하고 수면은 별도 운용 지침이 필요하다. 독·마비 규칙을 그대로 복사하지 않는다.

## W5. 랜스 스타일

**근거:** 사용자 운용 지식. 공식 동작 전수 검증값으로 취급하지 않는다.

| 스타일 | 운용·이유 | 별도 운용 조건 |

| 기본스타일 | 3단 찌르기·일반 카운터·뛰어들어찌르기 카운터 중심 | 가드 성능2~3 우선, 불퇴전·공격적인 방어 검토. 상세·미확정 기준은 아래 기본스타일 항목 |

### 저스트가드·실드태클의 기존 실행 기준

- 실드태클 레벨은 사용자 확인(2026-10-11) 기준. 저스트가드의 가드 성능 비권장을 복사하지 않는다.
- 반사는 점수에 임의 피해를 가산하지 않는다. 우선순위순에서는 고레벨을 우대하고 점수순에서도 최소1은 유지한다.
