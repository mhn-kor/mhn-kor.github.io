## 0. 용어·작성 규칙

| 용어 | 뜻 |
| --- | --- |
| 필수 최소 | 후보 자격. 미달이면 탈락 |
| 권장 (최소0 → 목표) | 미채용~목표를 비교. 미달만으로 탈락시키지 않고, 목표 충족 자체를 점수로 우대하지 않음 |
| 비권장 | 자동 보충에서 제외/낮춤. 겸용 장비는 금지하지 않음 |
| 적용 제외 | 그 무기·스타일·탄에서 효과를 점수에 넣지 않음 |
| 조건부 | 발동 가정으로 계산 (조건ON 점수). 상시 효과로 단정하지 않음 |

- **근거 표기:** 사용자 지침 / 공식 수치 / 조사 참고 / 개발 판단. **상태 표기:** 구현 / 미반영 / 미확정.
- 직접 지정은 내부 권장보다 우선한다. 단, 적용 불가·계산 제외를 유효 효과로 바꾸지 않는다.
- 새 지침은 **조건 → 판단(최소/목표) → 이유 → 예외 → 근거·상태**의 짧은 규칙·표로 정리한다. 숫자·이유·예외는 축약하지 않고, 모호한 의미는 사용자에게 확인한다.
- **지침 저장과 실행 반영은 별개다.** 적용 설계·미확정 사항을 확인한 뒤 구현하고, A5 현황표·테스트를 함께 갱신한다.

## 자동세팅 기본 원칙

사용자 합의 2026-10-11. 구현 설명보다 우선하는 목표 기준.

| 원칙 | 규칙 |
| --- | --- |
| 목적 | 정답 세팅 재현이 아니라 사람이 놓칠 수 있는 유용한 후보를 발견·계산·제안. 최종 판단은 사용자가 내 빌드에서 |
| 판단 순서 | 지침 원리 → 무기·몬스터·스타일·강화·파라미터 결합 → 방향 제안 → 방향 안 후보 탐색 → 근거·대안 → 사용자 수정 |
| 지침 해석 | 적힌 완성 조합만 반환하지 않고 원리로 새 조합 도출. 고정 프리셋 추가만으로 달성했다고 보지 않음. 실행 중 AI 호출 불필요 |
| 스타일과 스펙 | 스타일 = 운용 골격·조건, 몬스터 스펙·탄·강화·파라미터 = 투자 방향. 서로 덮어쓰지 않음 ('40%/60%'는 역할 설명이지 가중치 아님) |
| 세팅 방향 | 탐색 전에 전략·범위를 정함. 상위 점수 결과에 사후로 이름 붙이기 금지 |
| 점수 | 방향 안의 효율 비교 수단. 반사 등 점수 밖 운용 가치를 대체하지 않음 |
| 결과 수 | 최대5개. 의미 있게 다른 대안만. 무관·열등 후보로 억지 충원 금지 |
| 신규 데이터 | 새 장비의 실제 스킬·슬롯을 기존 원리로 평가. 필수 조건 비용이 줄면 남은 구성도 재검토 |
| 안전 | 없는 효과·필수 조건·배율을 만들지 않음. 사용자 지침과 개발 가설 구분 |
| 자료 조사 | 커뮤니티는 보충 근거. 사용자 지침을 조용히 대체하지 않음. 디시인사이드 제외 |

예: 같은 실드태클이라도 이블조는 흉회심1/3/5, 타마미츠네는 속성·경지/회심격/공격 증강 방향을 비교한다. 3회심이라는 이유로 속성 대안을 없애지 않는다. 우열은 계산으로 확인한다.

## A0. 기회비용을 고려한 장비 선택

**근거:** 2026-10-14 사용자 확정. **원칙:** 장비 단품의 최고점이 아니라, 그 장비를 채용한 전체 구성과 대체 장비로 부족분을 보완한 전체 구성을 비교한다.

### 필수 체크 (설계·구현·검수마다)

1. **동일 조건:** 무기·스타일·강화·파라미터·운용·조건부 가정을 비교안 사이에 유지. 가정이 다르면 별도 운용 대안.
2. **교체·보완:** 잃는 유효 스킬을 다른 부위·연성으로 보충한 구성까지 검토. 나머지 고정 단순 교체로 결론내지 않음.
3. **운용 성립:** 양쪽의 필수 최소·적용 범위·사용자 조건 확인. 보충 불가·미충족 사유 기록.
4. **전체 이득·손실:** 점수 차, 운용 장단점, 확보/포기 스킬, 연성 사용·남은 슬롯. 비용을 점수에서 또 빼는 중복 계산 금지.
5. **대체 가능성:** 연성 불가 효과·고레벨 보충 비용·선행조건 확인. 슬롯 수·고룡 부위 수·핵심 충족만으로 우대 금지.
6. **근거·검수:** 비교한 대안과 채택 이유 기록. 미탐색·미확정·탐색 제한을 명시하고 전역 최적이라 단정하지 않음.

예: 추격 갑옷3 유지·허리2 보충안과 허리2 유지·갑옷3 보충안을 모두 비교한다. 후자의 보충 비용이 커도 전체 이득이 크면 유리할 수 있다.
예 (부위 배치, 2026-10-16): 용맹+흉회심 빌드에서 용맹2를 장갑(오나즈치)에 두면 다리 자리에서 흉회심1(아오아시라)만 고를 수 있지만, 용맹2를 다리(바젤기우스)에 두면 장갑 자리에서 흉회심2(바젤기우스)를 고를 수 있다. 같은 뼈대를 어느 부위에 두느냐로 빈 자리의 선택지가 달라진다.

### 평가 축 (하나의 가중합을 만들지 않음)

| 축 | 뜻 |
| --- | --- |
| valid | 모든 필수 최소·슬롯·연성 제한 충족 |
| ON 점수 | 공유 계산식(bdStats)의 조건 발동 점수 |
| OFF 점수 | 선택적 전투 조건을 끈 점수. 보조 비교 축 (가동률·평균 혼합 없음) |
| 운용 수준 | 명시된 점수 밖 운용 스킬별 레벨 벡터 (반사·가드 성능·집중·회피 장전·SP 계열·강화 지속) |
| 연성 비용 | 실제 사용한 연성 칸 수 |

- 장비의 공격 효과는 점수에 이미 들어 있다. 고룡·추격 등에 가중치를 또 더하지 않는다. 연성 비용을 점수에서 빼지 않는다.
- 운용 수준은 실제 레벨이며 점수로 환산하지 않는다. 권장 목표 초과는 우대하지 않는다.

### 우열·추천

- **열등 제거:** 같은 정책·가정에서 A가 ON·OFF·운용 각 축에서 B 이상이고, 연성은 B 이하이며, 하나 이상 더 좋으면 B를 뺀다. 장단점이 갈리면 둘 다 유지한다 (임의 환산·허용 손실률 없음).
- **결과 선정 (abBest):** 열등 제거 후 서로 다른 방어구 조합 5개를 각 조합의 최고 ON 점수순으로 보여준다. 공격 고점 / 조건 OFF 최고 / 운용 스킬별 최고 / 연성 최소의 1위는 배지(🏅)를 달고, 그 방어구 조합은 5개 안에 반드시 포함한다 (모두 같은 값이면 배지 없음).
- **연성 안:** 같은 방어구에 연성만 다른 후보는 카드 안 탭 A/B/C(최대3, 스킬 구성이 다른 것만)로 묶는다. A = 그 조합의 최고 ON 점수, B·C = 그 조합의 배지 후보 또는 대안. A 대비 스킬·연성·점수 차이를 자동 요약한다. 정렬 선택은 없다.
- 결과 5개는 **서로 다른 방어구 조합**이다. 연성 배치만 다른 후보는 별도 결과가 아니라 연성 안 탭이다.
- 근거 표시는 실제 관측한 비교쌍(변경 부위·점수 차·운용 차·연성 차·우세/열세/장단점)만 쓴다. 비교하지 않은 장비를 근거로 만들지 않는다.


## A0-1. 레벨 효율·방어구/연성·버프 순위

후보 선별·동률 비교용 공통 규칙. 출처 번호(W3·W6·W7)는 기존 표기를 유지한다.

### W3. 스킬 레벨 투자 효율

레벨별 총효과·추가 증가량·장비/연성 비용·발동 조건·기회비용을 함께 비교한다.

| 증가 곡선 예시 | 판단 |
| --- | --- |
| 5/10/15/20/25% | 매 레벨 +5%p. Lv2·3·5 등 유연하게 비교 |
| 10/15/20/30/40% | 추가량 10/5/5/10/10%p. Lv1 저투자와 Lv3 이상 → Lv4·5 투자안 비교 (Lv3 자체를 최적·필수로 단정하지 않음) |
| Lv1 초기 효율이 높음 | 여러 스킬 Lv1 조합('다이소') 검토 |

- 최소와 목표를 분리한다. 별도 지침이 없으면 Lv1~목표를 비교한다 (MAX−2~MAX 고정 범위는 폐기).
- 같은 단위의 단일 효과만 곡선 비교한다. 복합·확률·비수치 효과를 하나의 피해 배율로 환산하지 않는다.
- 예시 수치는 공식 스킬 수치를 대체하지 않는다.

### W6. 방어구·연성 우선순위

**근거:** 2026-10-12 사용자 지침. 상위 기준은 [A0](AUTO_BUILD.md#a0-기회비용을-고려한-장비-선택): 아래는 **후보 선별·동률 비교용**이며 최종 판단은 교체·보완 후 전체 구성 비교다.

| 순서 | 기준 | 제한 |
| --- | --- | --- |
| 1 | 운용에 중요한 연성 대체 불가 스킬을 가진 장비 | 무관한 스킬까지 우대하지 않음 |
| 2 | 연성 가능 스킬은 한 부위의 높은 레벨 | 교체 시 필요 연성 칸·다른 부위 기회비용 비교 |
| 3 | 유효 스킬의 레벨 합·효과 | 스킬 종류 수로 평가하지 않음 |
| 4 | 적은 연성 비용으로 대체할 부위는 교체하고 대체 불가 효과 확보 | 특정 부위 고정·2소켓 금지로 해석하지 않음 |

- 유틸(내성·상태이상 속성 강화·귀마개·풍압 등)은 낮은 우선순위. 강화 지속은 무기·스타일에 유효하면 상대적으로 높게 본다.
- 명시된 운용 필수(상태이상 축적, 가드 성능·반동·장전 등)는 낮은 우선순위로 덮어쓰지 않는다.
- 장비 기본 스킬을 먼저 평가하고 연성으로 핵심을 보충한다. 슬롯 수 자체에는 가산점이 없다. 필요한 필수 연성 칸은 확보한다.
- 연성 배치: 같은 기본 스킬이 붙은 부위의 빈 슬롯 우선 → 없으면 다른 부위. 기존 연성은 덮어쓰지 않는다. 재사용성 규칙일 뿐 피해 보너스가 아니다.
- 연성전용 핵심은 명시 최소를 채운 뒤 장비·연성 이득을 비교한다. 남은 칸을 1·2·3순위 MAX로 순서대로 채우지 않는다.
- 예시 (사용자): 에스피나스 추격 갑옷Lv3 / 허리Lv2 → 갑옷 유지·허리Lv2 연성 보충안을 먼저 보되, 다른 갑옷의 더 중요한 효과도 비교한다.

### W7. 버프 종류별 우선순위

**근거:** 2026-10-12 사용자 공통 지침. 순위는 **분류 순서**이며 대미지 배율·가중치가 아니다.

| 순위 | 효과 | 발동 조건 | 방식 |
| --- | --- | --- | --- |
| 1 / 2 | 대미지 버프 | 없음 / 있음 | % |
| 3 / 4 | 공격력·속성 버프 | 없음 / 있음 | % |
| 5 / 6 | 대미지 버프 | 없음 / 있음 | +고정값 |
| 7 / 8 | 공격력·속성 버프 | 없음 / 있음 | +고정값 |

- 적용 가능한 공격 후보끼리 비교할 때 쓴다. 운용 필수·사용자 핵심 순위·무기별 예외가 우선한다.
- 적용 불가·계산 제외 효과를 이 순위로 되살리지 않는다. 점수순 정렬은 실제 점수가 우선이다.
- 회심·복합·체력 의존·회심 비례 효과는 단일 분류에 넣지 않고 기존 계산으로 비교한다. 경지의 장착 레벨 선행조건은 전투 유지 조건이 아니다.

## A1. 화면·사용자 설정

| 항목 | 기준 |
| --- | --- |
| 진입 | 빌드 추가/상세 수치/빌드 목록 옆 '자동빌드 (테스트중)'. 내부 별도 화면 |

## A8. 지침 작성 양식

사용자가 '자동빌드 작성자료 기준'을 물으면 제공한다. 서술형으로 받아도 된다 (플레이 영상을 설명하듯). 받은 내용은 해당 무기 운용 가이드(`docs/weapons/*.md`) 틀로 요약하고, 동작 사실은 무기 특성 표, 스킬 사실은 스킬 사전으로 나눠 넣는다. 해석이 갈리는 부분은 반영 전에 확인한다. 답할 수 있는 항목만 받는다.

1. 무기 / 스타일 / 성향 이름 (같은 스타일 안에서 갈리는 운용)
2. 어떤 컨셉으로 돌아가는 스타일인지, 어떻게 공격하는지 (주력 동작·이유) → 무기 특성의 동작 유무도 여기서 정한다
3. 꼭 필요한 스킬과 최소 레벨
4. 주로 쓰는 스킬, 목표 레벨, 이유
5. 쓰지 않는 스킬·함께 쓸 수 없는 스킬과 이유 (불필요 vs 적용 불가 구분)
6. 보우건: 주력 탄·장전/반동 레벨
7. 예외 상황, 점수에 쓸 조건부 효과
8. 출처·확인일·검증 여부
