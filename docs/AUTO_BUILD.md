## 0. 용어·작성 규칙

| 용어 | 뜻 |
| --- | --- |
| 필수 최소 | 후보 자격. 미달이면 탈락 |
| 권장 (최소0 → 목표) | 미채용~목표를 비교. 미달만으로 탈락시키지 않고, 목표 충족 자체를 점수로 우대하지 않음 |
| 비권장 | 자동 보충에서 제외/낮춤. 겸용 장비는 금지하지 않음 |
| 적용 제외 | 그 무기·스타일·탄에서 효과를 점수에 넣지 않음 |
| 조건부 | 발동 가정으로 계산 (조건ON 점수). 상시 효과로 단정하지 않음 |

- **근거 표기:** 사용자 지침 / 공식 수치 / 조사 참고 / 개발 판단. **상태 표기:** 구현 / 미반영 / 미확정.
- 직접 지정은 내부 권장보다 우선한다. 단, 적용 불가·계산 제외를 유효 효과로 바꾸지 않는다.
- 새 지침은 **조건 → 판단(최소/목표) → 이유 → 예외 → 근거·상태**의 짧은 규칙·표로 정리한다. 숫자·이유·예외는 축약하지 않고, 모호한 의미는 사용자에게 확인한다.
- **지침 저장과 실행 반영은 별개다.** 적용 설계·미확정 사항을 확인한 뒤 구현하고, A5 현황표·테스트를 함께 갱신한다.

## 자동세팅 기본 원칙

사용자 합의 2026-10-11. 구현 설명보다 우선하는 목표 기준.

| 원칙 | 규칙 |
| --- | --- |
| 목적 | 정답 세팅 재현이 아니라 사람이 놓칠 수 있는 유용한 후보를 발견·계산·제안. 최종 판단은 사용자가 내 빌드에서 |
| 판단 순서 | 지침 원리 → 무기·몬스터·스타일·강화·파라미터 결합 → 방향 제안 → 방향 안 후보 탐색 → 근거·대안 → 사용자 수정 |
| 지침 해석 | 적힌 완성 조합만 반환하지 않고 원리로 새 조합 도출. 고정 프리셋 추가만으로 달성했다고 보지 않음. 실행 중 AI 호출 불필요 |
| 스타일과 스펙 | 스타일 = 운용 골격·조건, 몬스터 스펙·탄·강화·파라미터 = 투자 방향. 서로 덮어쓰지 않음 ('40%/60%'는 역할 설명이지 가중치 아님) |
| 세팅 방향 | 탐색 전에 전략·범위를 정함. 상위 점수 결과에 사후로 이름 붙이기 금지 |
| 점수 | 방향 안의 효율 비교 수단. 반사 등 점수 밖 운용 가치를 대체하지 않음 |
| 결과 수 | 최대5개. 의미 있게 다른 대안만. 무관·열등 후보로 억지 충원 금지 |
| 신규 데이터 | 새 장비의 실제 스킬·슬롯을 기존 원리로 평가. 필수 조건 비용이 줄면 남은 구성도 재검토 |
| 안전 | 없는 효과·필수 조건·배율을 만들지 않음. 사용자 지침과 개발 가설 구분 |
| 자료 조사 | 커뮤니티는 보충 근거. 사용자 지침을 조용히 대체하지 않음. 디시인사이드 제외 |

예: 같은 실드태클이라도 이블조는 흉회심1/3/5, 타마미츠네는 속성·경지/회심격/공격 증강 방향을 비교한다. 3회심이라는 이유로 속성 대안을 없애지 않는다. 우열은 계산으로 확인한다.

## A0. 기회비용을 고려한 장비 선택

**근거:** 2026-10-14 사용자 확정. **원칙:** 장비 단품의 최고점이 아니라, 그 장비를 채용한 전체 구성과 대체 장비로 부족분을 보완한 전체 구성을 비교한다.

### 필수 체크 (설계·구현·검수마다)

1. **동일 조건:** 무기·스타일·강화·파라미터·운용·조건부 가정을 비교안 사이에 유지. 가정이 다르면 별도 운용 대안.
2. **교체·보완:** 잃는 유효 스킬을 다른 부위·연성으로 보충한 구성까지 검토. 나머지 고정 단순 교체로 결론내지 않음.
3. **운용 성립:** 양쪽의 필수 최소·적용 범위·사용자 조건 확인. 보충 불가·미충족 사유 기록.
4. **전체 이득·손실:** 점수 차, 운용 장단점, 확보/포기 스킬, 연성 사용·남은 슬롯. 비용을 점수에서 또 빼는 중복 계산 금지.
5. **대체 가능성:** 연성 불가 효과·고레벨 보충 비용·선행조건 확인. 슬롯 수·고룡 부위 수·핵심 충족만으로 우대 금지.
6. **근거·검수:** 비교한 대안과 채택 이유 기록. 미탐색·미확정·탐색 제한을 명시하고 전역 최적이라 단정하지 않음.

예: 추격 갑옷3 유지·허리2 보충안과 허리2 유지·갑옷3 보충안을 모두 비교한다. 후자의 보충 비용이 커도 전체 이득이 크면 유리할 수 있다.

### 평가 축 (하나의 가중합을 만들지 않음)

| 축 | 뜻 |
| --- | --- |
| valid | 모든 필수 최소·슬롯·연성 제한 충족 |
| ON 점수 | 공유 계산식(bdStats)의 조건 발동 점수 |
| OFF 점수 | 선택적 전투 조건을 끈 점수. 보조 비교 축 (가동률·평균 혼합 없음) |
| 운용 수준 | 명시된 점수 밖 운용 스킬별 레벨 벡터 (반사·가드 성능·집중·회피 장전·SP 계열·강화 지속) |
| 연성 비용 | 실제 사용한 연성 칸 수 |

- 장비의 공격 효과는 점수에 이미 들어 있다. 고룡·추격 등에 가중치를 또 더하지 않는다. 연성 비용을 점수에서 빼지 않는다.
- 운용 수준은 실제 레벨이며 점수로 환산하지 않는다. 권장 목표 초과는 우대하지 않는다.

### 우열·추천

- **열등 제거:** 같은 정책·가정에서 A가 ON·OFF·운용 각 축에서 B 이상이고, 연성은 B 이하이며, 하나 이상 더 좋으면 B를 뺀다. 장단점이 갈리면 둘 다 유지한다 (임의 환산·허용 손실률 없음).
- **역할별 대표 (기본 정렬):** 공격 고점 → 조건 OFF 효율 → 운용 스킬별 보완 → 연성 저투자 → 남은 자리는 다른 투자 대안. 같은 후보가 여러 역할을 채우면 한 번만.
- **점수순 정렬:** 순수 ON 점수 내림차순.
- 결과 5개는 **서로 다른 방어구 조합**이다. 연성 배치만 다른 후보를 여러 개 추천하지 않는다 → 현재 코드 위반, A6 참고.
- 근거 표시는 실제 관측한 비교쌍(변경 부위·점수 차·운용 차·연성 차·우세/열세/장단점)만 쓴다. 비교하지 않은 장비를 근거로 만들지 않는다.

## A2. 방향 생성 (현재 구현)

`abInvestmentDirections` / `abDirections`. 최대3개 + 직접 설정.

| 무기 조건 | 생성 방향 (핵심3개) |
| --- | --- |
| 자체 역회심 & 3회심 아님 | 흉회심 저투자(→1) / Lv3 / Lv5 + 상태이상·속성·연격 + 돌파구. 대검(수류베기 제외)은 Lv5 먼저 |
| 상태이상 무기 | 추가 공격 중심 (+고룡 독/폭파 또는 축적 시 위력 UP). 건랜스 블래스트 대시는 후방 축적 방향 추가 |
| 속성 무기 | 속성·경지 중심 / 고룡·혼합 (고룡 레벨당 증가가 크면 앞으로) |
| 물리 무기 | 연격·돌파구·용맹 |
| 자체 회심 > 0 | + 회심격(속성) 또는 자체 회심 투자. 3회심이면 + 공격 증강【회심】. 슬래시액스는 변형 공격·회심 활용이 일반 회심 방향을 대체 |
| 스타일 보정 | 규칙 행의 `coreSlot`: 권장 첫 스킬이 핵심에 없으면 해당 칸에 넣음 (한손검 폴배시 3번째·저스트 교격, 대검 수류베기 외 2번째·차지 마스터/저스트 모으기 해방). `label`: 방향 이름 접두 (폴배시) |

스타일 운용 규칙은 [무기 지침 규칙 일람](WEAPON_SETTING_GUIDE.md#규칙-일람-무기스타일)의 필수/권장/비권장으로 핵심과 합쳐진다. 규칙 데이터는 `auto-build.js`의 `AB_RULES` 한 곳에 있다: 스타일·성향 행(`styles`), 보우건 탄 운용(`gunModes`), 무기 공통(`weapons`: 출처·동시 발동 불가 조건), 문맥별 자동 보충 제외(`avoid`), 효과 적용 범위(`scopes`), 점수 밖 운용 스킬(`operation`). 아래 A3의 적용 범위·제외 항목도 이 데이터로 판정한다.

## A3. 점수·적용 범위

**공통:** 기존 bdStats를 공유하는 비교 점수. 실제 DPS가 아니며 모션·육질·약점·무기 고유 보정·조건 유지율은 모델링하지 않는다.

| 항목 | 기준 |
| --- | --- |
| 계산식 | [나우칼 간이 계산기](https://mhnowcalc.com/calc/damage_calc.php?lang=ko) 공개식과 대조. 공격 자동 상승분은 배율 전, 공격 파라미터는 배율 후, 공격 활성은 고정 증가분까지 곱함. 회심격은 회심 분기의 속성% 증가에 합산. 일반/회심을 각각 계산 후 회심률로 평균. 중간값 반올림 없음 |
| 조건부 스킬 | 발동 가정 (ON 점수). OFF 점수를 따로 표시 |
| 특수 위력·SP 전용 공격 | OFF. 직접 핵심 지정 가능, 가져온 뒤 체크 조정 가능. SP 가속은 후보 유지하되 피해로 환산 안 함 |
| 공중 조건 | 한손검 기본 폴배시에서만 |
| 모으기 조건 | 대검·해머·활에서만 (해머는 개발 판단). 활 회피근접공격은 제외해야 함 (W11, 미반영) |
| 공격적인 방어 | 한손검·랜스·건랜스·차지액스·헤비, 대검 격앙참 |
| 저스트 교격 | 한손검 기본 폴배시에서만. 【지속】은 제외 |
| 상태이상 | 축적 위력·추가 공격은 무기 상태이상 일치 또는 슬래시액스 독/마비병만. 축적 수치는 표시만 하고 피해 합산 제외 |
| 회심 계열 제외 | 자체 역회심(3회심 제외)은 간파·약점 특효·슈퍼회심·회심격 자동 보충 제외. 회심 불가 탄 기준이면 회심 계열 전부 제외 |
| 기습 상태 이상 | 건랜스 블래스트 대시 외 자동 보충 제외 |
| 탄 강화·포술 | 보우건 B5 기준. 포술은 건랜스 메인 점수 제외(포격 별도 계산), 차지액스·철갑/용격만 |
| 랜스 | 불퇴전ON·매진OFF. 반사 피해 가산 없음 |
| 활 집중 | 집중 주기 보정은 자동추천에서 끔 (빌드 기능은 유지) |

## A4. 탐색 파이프라인 (현재 구현)

- 제한 도달 시 확보한 결과를 반환하고 '탐색 제한 도달'·'기회비용 검토 일부 미완료'를 표시한다. 메인 스레드에서 짧게 양보하며 취소/설정 변경 시 이전 작업을 버린다.
- 교체는 한 라운드뿐이다. 새 대표로 반복하는 2~3라운드와 양방향 대안의 동일 예산 전수 비교는 미구현이다.

## A8. 지침 작성 양식

사용자가 '자동빌드 작성자료 기준'을 물으면 제공한다. 서술형으로 받아도 되며, 요약해 규칙 일람의 해당 행으로 정리하고 해석이 갈리는 부분은 반영 전에 확인한다. 답할 수 있는 항목만 받는다.

1. 무기군 / 스타일 / 성향 이름 (같은 스타일 안에서 갈리는 운용)
2. 어떻게 플레이하나 (주력 동작·이유)
3. 꼭 필요한 스킬과 최소 레벨
4. 선호 스킬, 목표 레벨, 이유
5. 피하는 스킬·적용 불가 스킬과 이유 (불필요 vs 적용 불가 구분)
6. 보우건: 주력 탄·장전/반동 레벨
7. 예외 상황, 점수에 쓸 조건부 효과
8. 출처·확인일·검증 여부
