## 자동세팅 기본 원칙

사용자 합의: 2026-10-11. 이후 자동세팅의 설계·구현·검토·신규 데이터 대응은 이 원칙 위에서 해석한다. 기존 구현 설명과 충돌하면 이 원칙을 목표 기준으로 삼되, 지침 저장만으로 실행 로직을 변경하지 않는다.

### 목적과 판단 순서

정답이나 알려진 세팅 하나를 재현하는 페이지가 아니라, 충분한 운용 지식과 실제 데이터를 이용해 사람이 놓칠 수 있는 유용한 세팅 후보를 발견·계산·제안하는 페이지다. 사용자는 최대 5개 추천을 내 빌드로 옮겨 수정하고 판단한다. 전역 최적해나 모든 사용자에게 정답인 빌드는 요구하지 않는다.

판단 순서: 지침의 이유·원리 이해 → 무기·몬스터·스타일·강화·파라미터와 결합 → 세팅 방향 제안 → 사용자가 선택한 방향 안에서 후보 탐색·계산 → 근거와 대안 제시 → 사용자 커스텀.

### 지침은 답안이 아니라 판단 지식

- 사용자 지침의 플레이 방식, 필수·권장·비권장 스킬, 투자 효율, 주요 포인트와 주의점을 판단 근거로 사용한다. 문서에 완성된 조합이 직접 적혀 있을 필요는 없다. 원리와 실제 데이터를 결합해 새로운 조합·스킬 우선순위·투자 방향을 도출한다.
- AI의 역할은 개발 과정에서 이 지식을 해석하고, 사람이 생각하지 못한 조합도 탐색 가능한 로직으로 일반화하는 것이다. 실행 중 AI 호출을 요구하는 원칙은 아니며 고정 프리셋을 늘리는 것만으로 달성했다고 보지 않는다.
- 새로운 조합의 추론은 허용하지만 존재하지 않는 스킬 효과·무기 특성·필수 조건·대미지 배율을 지어내지는 않는다. 사용자 운용 지식, 확인된 수치·계산식, 개발 과정에서 도출한 추천 가설을 구분한다. 판단에 필요한 모호한 기준은 사용자에게 확인한다.
- 커뮤니티는 부족한 지식을 보충하는 참고이며 사용자 지침을 조용히 대체하지 않는다. 자료를 조사할 때 디시인사이드는 제외하고, 충돌·불확실성은 확인한다.

### 스타일과 무기 투자 방향의 결합

- 스타일은 공격·가드·이동 등 운용 골격과 필요한 조건을 정한다. 몬스터 소재 무기의 스펙·속성·회심·병·탄과 강화·파라미터는 그 골격 안의 투자 방향을 정한다. 스타일 조건과 무기 방향을 결합하며 어느 한쪽으로 다른 쪽을 덮어쓰지 않는다.
- 사용자의 '스타일 40% / 몬스터 스펙 60%'는 이 역할 구분을 설명한 표현이지 고정 점수 가중치·장비 비율이 아니다.
- 같은 스타일도 무기·파라미터가 다르면 다른 방향을 제안한다. 같은 핵심 스킬 3개도 남은 장비·연성·보조 스킬·투자 레벨은 운용과 스펙에 따라 달라질 수 있다. 핵심 3개는 탐색의 중심이지 전체 빌드를 고정하는 완성 답안이 아니다.
- 필수 최소 조건, 권장 목표, 비권장, 적용 불가를 구분한다. 권장 사항을 모두 강제해 변주를 막지 않는다. 반사처럼 점수에 없는 운용 중요도도 추천에 유지하되 가짜 대미지 점수로 환산하지 않는다.

예시: 이블조 실드태클은 가드 운용 기준을 유지하면서 흉회심 저투자/Lv3 균형/Lv5 투자 방향을 비교한다. 타마미츠네의 동일 스타일에서는 속성 파라미터에 따른 속성·경지 투자, 회심 파라미터에 따른 회심격·공격 증강 활용 등을 검토한다. 이는 판단 원리의 예시이며 방향별 실제 성립·우열은 장비 조합과 계산으로 확인한다. 선택한 파라미터를 임의로 바꾸거나 3회심이라는 이유만으로 속성 비교안을 무조건 없애지 않는다.

### 세팅 방향·탐색·점수의 역할

- 세팅 방향은 불필요하게 광범위한 조합을 훑기 전에 투자 전략과 탐색 범위를 정하는 중간 단계다. 전체 점수 상위 조합을 먼저 뽑고 사후에 이름만 붙이는 방식이 아니다.
- 사용자 지침과 선택 무기의 특징으로 의미 있는 방향을 제안하고, 선택된 방향의 핵심 조건·효율 구간 안에서 충분한 후보를 제한 탐색한다. 점수는 그 안의 효율 비교 수단이며 플레이 지침을 무시하고 방향을 정하는 단독 기준이 아니다.
- 최대 5개 결과는 동일 투자 구성의 작은 장비 교체만 반복하기보다, 선택한 방향 안에서 의미 있게 다른 투자·보조 스킬 대안도 검토한다. 억지로 다섯 개를 채우거나 미충족·무관한 후보를 섞지 않는다. 다양성의 선정 방식·허용 점수 차이는 후속 설계에서 확인하며 임의 보너스로 실제 점수를 바꾸지 않는다.
- 각 방향과 결과에 무엇을 활용했고 어떤 조건·투자 비용·장점·한계가 있는지 설명한다. 일반 공격·조건부 공격·특정 공격의 효과와 실제 DPS를 혼동하지 않는다. 기존 특수 위력 OFF 등 점수 가정과 사용자 직접 수정 우선권은 유지한다.

### 신규 데이터와 후속 검수

새 무기·장비는 실제 스펙·스킬·슬롯을 기존 원리에 넣어 평가한다. 필수 조건을 더 적은 장비로 충족하면 남은 부위·연성의 투자 전략까지 재검토할 수 있어야 한다. 알려진 빌드나 특정 장비 ID를 매번 사람이 등록해야만 추천되는 구조를 목표로 삼지 않는다. 새로운 효과·운용은 필요한 데이터와 판단 지식을 보충한다.

후속 변경에서는 (1) 같은 스타일에서 다른 몬스터·파라미터의 방향이 달라지는지, (2) 같은 핵심 3개에서도 보조 구성이 달라지는지, (3) 신규 장비의 겸용 스킬·슬롯으로 새 후보가 생기는지, (4) 점수 밖의 운용 중요도가 유지되는지, (5) 설명된 방향과 실제 추천이 일치하는지 검토한다. 이 원칙의 저장과 실행 로직의 구현 완료는 별개로 보고한다.

## 합의된 요구사항

보우건 후속 설계 전 `BOWGUN_HANDLING.md`를 함께 검토한다. 라이트·헤비 두 스타일이 대체하는 반동/장전은 자동 보충에서 제외하며 가드리로드의 가드 성능은 최소0/목표3 권장 후보로 연결했다. 직접 지정·겸용 장비와 기존 몬스터별 투자 방향은 보존한다. 탄 슬롯별 조사 자료는 참고용이며 탄별 필수 레벨, 특정 탄 반복·회피/SP 연계 및 탄 강화·사격 DPS는 미반영이다. 화면에도 탄별 요구는 직접 지정하도록 안내한다.

- 빌드 메뉴의 빌드 추가 / 상세 수치 / 빌드 목록 옆 자동빌드 버튼. 메뉴는 추가하지 않고 내부 별도 화면으로 전환한다.
- 내 빌드 복귀 시 필터/스크롤 보존. 가져오기는 최신 위치에 삽입, 필터 해제, 해당 카드 포커스.
- 무기군 / 몬스터 / 스타일 / 스타일강화 Lv20 / Lv10·15·20 파라미터 설정 후 최종 무기 수치로 방향을 추천한다.
- 방향 1~3개 + 직접 설정. 방향 선택은 핵심 스킬 프리셋을 채우고 자유롭게 수정 가능. 사용자 수정 내용은 무기 설정 변경으로 자동 덮어쓰지 않는다.
- 핵심 스킬 3개, 1→2→3순위는 무기의 투자 방향이다. 스타일 운용 조건은 별도로 합친다. 일반 방향의 기본 최소=1, 목표=MAX이며, 스타일 필수 조건이 함께 있으면 투자 방향의 2·3순위는 최소=0(권장)으로 시작한다. 사용자 범위 조정 가능. 최소는 후보 자격 조건, 목표는 충족도 평가 기준. 필수 경지를 선택하면 설명의 선행 스킬 레벨도 확보한다. 장비 자체의 초과 레벨을 버리지는 않지만 평가 레벨은 목표까지다.
- 제한 내 많은 후보를 탐색하고 최대 5개 추천. 최소 미충족은 제외, 같은 방어구 조합 중복 제외, 스킬 우선순위순 / 빌드 점수순 정렬.
- 연성 사용/미사용. 슬롯당 Lv1, SMELT의 실제 스킬과 그룹을 사용. 핵심 부족분 보충 후 남은 슬롯의 소수 공격 후보 평가. 실제 넣은 연성만 점수에 포함하며 보유 연성은 아직 고려하지 않는다.
- 연성 사용 옆 ‘록온 필수’. 근접무기 선택 시 기본 ON, 라이트보우건/헤비보우건/활은 OFF·비활성화. ON이면 핵심 스킬 3개를 유지하고 내부 0순위 필수 조건으로 록온 Lv1을 확보한다. 단품 후보 선정·가지치기·연성 보충·최종 자격 검사에 반영하며 정렬 방식과 무관하게 미충족 후보는 제외한다. 기존 무기/장비로 충족하면 추가 확보하지 않고, 핵심 스킬에도 록온을 선택했으면 중복 요구하지 않는다. 초과 레벨은 가중하지 않는다.
- 기존 bdStats 점수 사용. 조건부 효과 발동 가정, 특수 위력 및 SP 전용 공격 효과 OFF. 가속 스킬은 후보와 핵심 스킬에서 유지하되 임의 대미지 배율로 환산하지 않는다. 각성의 일격은 개발 대상 제외. 포술/집중 추가 개발은 완료 처리.
- 무기별 운용 가이드는 사용자가 추후 제공. 플레이 경험 기반 필수·비권장 규칙을 임의로 확정하지 않는다.

## 현재 샘플 범위 및 한계

아래는 현재 구현 현황이다. 스타일의 단일 프리셋 반환을 제거하고 운용 조건과 무기 투자 방향을 결합했다. 같은 랜스 스타일에서도 이블조는 흉회심 1/3/5, 타마미츠네는 속성·경지/회심격/공격 증강 방향을 검토한다. 실제 무기 스펙·강화·선택 파라미터와 등록 장비의 스킬 효과로 판단하며, 모든 무기의 미제공 운용 지식까지 완성된 것은 아니다.

등록된 전체 몬스터·이벤트 소재 무기를 지원한다. 선택한 무기군에 해당하는 소재만 공식 방어구 순번으로 표시하며, 무기군 변경 시 해당 소재에 무기가 없으면 목록의 첫 소재로 전환한다. 소재 변경 시 스타일·강화·파라미터를 초기화하고 사용자 수정 핵심 스킬은 보존한다. 스타일/강화는 기존 BD_STYLE_DATA와 BD_STYLES 기준이다.

방향은 무기·스타일·강화 후 자체 회심·선택 파라미터와 WEAPON_SETTING_GUIDE.md의 사용자 지침으로 결정한다. 이전 고정 속성/회심 프리셋과 40% 분기점은 사용하지 않는다. 회심 파라미터 3개는 회심격 및 공격 증강 방향을 우선 검토하고, 회심 중심 방향은 발동 가정 유효 회심 80% 이상을 추천 자격으로 검사한다. 슈퍼회심은 일반 필수가 아니며 슬래시액스의 변형 공격 방향에서 별도로 검토한다.

기본 역회심 무기는 흉회심 Lv1/3/5 방향을 비교한다. 대검은 Lv5 고점 방향을 먼저 표시하되 실제 평균 점수에 보너스를 더하지 않는다. 회심 파라미터 3개를 선택하면 흉회심 방향·자동 보충을 제외한다. 원래 붙은 흉회심이나 사용자 직접 지정은 보존한다. 전심전력은 낮은 우선순위 후보이며 금지하지 않는다.

상태이상은 해당 추가 공격을 목표 Lv5로 추천하고 독·폭파 고룡 축적 효과 및 블래스트 대시의 후방 축적 예외를 반영한다. 독병·마비병도 기존 일치 검사로 인정한다. 저스트가드는 불퇴전 4~5 / 반사 1~최대를 별도 최소 조건으로 확보하고 매진 2~3은 보완 권장으로 비교한다. 실드태클은 가드 성능 5 / 반사 1~최대 / 불퇴전 4~5를 별도로 확보한다. 화면의 '스타일 운용 기준 적용'을 끄면 자동 조건을 해제하되 직접 선택한 핵심은 유지한다. 저스트가드에서 가드 성능은 자동 보충하지 않지만 해당 장비 자체를 금지하지 않는다. 반사는 실제 대미지를 꾸며내지 않고 우선순위 정렬에서 목표 레벨을 우대한다.

속성 방향은 등록 장비에 해당 경지가 있으면 속성·경지를 함께 검토하고 해당 속성 고룡 효과를 실제 설명으로 연결한다. 3회심에서도 속성 방향은 남긴다. 신규 장비의 기본 스킬을 수집하고 실제 효과·무기 적용 범위로 보조 후보를 재평가한다. 같은 단위의 효과와 무기 기본 스펙으로 선별용 상대 효율을 구하되 이는 최종 점수에 더하지 않는다. 보조 연성은 선별 후보 최대 12개 등을 실제 bdStats 점수로 비교한다. 공중 운용 지침 없는 비연, 근접의 적정 거리, 상태이상이 없는 축적 시 위력, 모으기 운용이 확인되지 않은 무기의 차지 마스터는 범용 보조 추천으로 오인하지 않는다. 아직 등록되지 않거나 계산에 해석되지 않는 신규 효과는 데이터·판단 지식 보충이 필요하다.

결과의 '투자 대안 비교'는 최고 점수 후보 이후 보조 스킬·레벨 구성이 다른 후보를 점수 내림차순으로 찾고, 같은 방어구 조합은 중복하지 않는다. 별도 점수 보너스나 임의 허용 손실률은 없으며 최고 후보와의 실제 점수 차이를 표시한다. 기존 우선순위순과 점수순 정렬은 그대로 유지한다. 대안이 부족하면 기존 순서의 남은 후보로 채우며 미충족 후보를 넣지는 않는다.

방어구 후보는 BUILD의 모든 세트다. 아직 제공되지 않은 개별 무기 운용과 보우건 탄별 방향·필수 장전/반동 기준은 임의로 확정하지 않는다. 사용자 수정 스킬은 자동 방향보다 우선하며, 미수정 방향은 무기·스타일·파라미터 변경 때 재평가한다.

전체 방어구를 단품 평가한 뒤 핵심 스킬·점수·운용 지침의 주요 스킬 기준으로 부위별 최대 24개를 추린다. 그 조합을 단계별 beam(최대 160개 유지)으로 제한 탐색한다. 단일 효과의 실제 레벨별 증가 곡선을 우선순위 탐색에 반영하고, 복합·확률·비수치 효과는 임의 %로 환산하지 않는다. 우선순위 경로와 점수 경로를 함께 보존하며 불가능한 최소 조건은 낙관적 상한으로 가지치기한다. 연성은 핵심 우선 / 점수 우선 / Lv1 중심 저투자 세 경로로 보충하며 모두 필수 최소 조건을 유지한다. 전역 최적해나 모든 연성 조합을 보장하지 않는다. 브라우저 메인 스레드에서 짧은 단위로 양보하며 취소·설정 변경 시 이전 작업을 폐기한다. 제한 도달 및 탐색량을 화면에 표시한다.

조건부 효과의 유지율은 미보정인 비교 점수다. 랜스 지침 적용 스타일에서는 불퇴전 발동을 가정하고 이동 후 보완용 매진은 동시에 켜지 않는다. SP 위력 OFF가 해금/기본 데이터 삭제를 의미하지 않는다. 사용자가 핵심 스킬로 SP 위력을 선택할 수는 있다. 추천 이후 내 빌드에서 체크를 바꿀 수 있다. 활 집중 사이클은 추천에서 미적용이며 기존 점수 기능 자체는 변경하지 않는다. 상태이상 임계치·발동 횟수·유지율 모델은 미구현이며 축적 효과를 임의 대미지 배율로 환산하지 않는다.

연성 배치 지침: 같은 스킬이 기본으로 붙어 있는 부위의 빈 슬롯을 우선 사용한다. 해당 부위가 없거나 슬롯이 부족하면 다른 부위에 배치한다. 핵심 최소 레벨 보충·추가 핵심 레벨·점수용 연성에 동일하게 적용하며, 기존 연성은 덮어쓰지 않는다. 재사용하기 좋은 배치를 위한 규칙이며 장비 조합의 점수·스킬 우선순위 자체는 변경하지 않는다.

추천 카드 표시: 장비명 옆에 몬스터명을 작게 표시하고, 바로 아래 한 영역에 기본 스킬과 연성 스킬을 함께 배치한다. 연성은 색상 보석 슬롯과 점선 테두리 스킬 칩으로 구분하며 별도 연성 행은 만들지 않는다. 계산 근거는 요구 스킬 충족(각 최소·목표·확보 레벨), 연성 배치, 점수 가정, 기대 점수로 나눈다.

계산 순서는 나우칼 간이 계산기(https://mhnowcalc.com/calc/damage_calc.php?lang=ko)의 공개식에 맞춘다. 공격 자동 상승분은 일반 배율 전에, 공격 파라미터는 배율 후에 더하며 공격 활성은 고정 증가분까지 곱한다. 회심격은 회심 분기의 일반 속성 배율에만 합산하고, 일반·회심 공격 대미지를 각각 구한 뒤 회심률로 평균한다. 상단 속성은 평균값이며 점수에 회심 기대배율을 중복 적용하지 않는다. 중간값은 반올림하지 않고 표시와 최종 점수만 반올림한다. 자동빌드도 같은 계산과 근거 표시를 공유한다. 상태이상 점수 모델과 약점·육질·모션·무기 고유 보정은 이번 변경 범위 밖이다.

추가 공격【독/마비/폭파】는 무기의 상태이상이 일치할 때만 계산하고 핵심 스킬 선택지에 제공한다. 슬래시액스의 독병·마비병도 해당 상태이상으로 인정한다. 파티원이 부여하는 상태이상은 이 비교 계산에서 가정하지 않는다. 무관한 추가 공격 스킬이 방어구에 함께 붙어 있더라도 점수 가산은 하지 않으며, 착용 스킬 목록 자체를 삭제하지는 않는다.
