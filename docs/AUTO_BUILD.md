# 자동빌드 작업 지침 / 전체 몬스터 테스트

무기·스타일별 세팅 방향을 설계/수정할 때 `WEAPON_SETTING_GUIDE.md`의 사용자 공통 지침과 운용별 기준을 먼저 검토한다. 문서 지침과 현재 실행 로직의 반영 여부를 구분한다.

최초 자동빌드 원복 기준: `fb6c497` (2026-10-11). 전체 몬스터 확장 전 배포 기준은 `be19501`이다. 원복 시 이후 사용자 변경과 저장된 빌드를 보존해야 한다. 커밋·푸시는 사용자 요청에 따라 진행한다.

## 합의된 요구사항

- 빌드 메뉴의 빌드 추가 / 상세 수치 / 빌드 목록 옆 자동빌드 버튼. 메뉴는 추가하지 않고 내부 별도 화면으로 전환한다.
- 내 빌드 복귀 시 필터/스크롤 보존. 가져오기는 최신 위치에 삽입, 필터 해제, 해당 카드 포커스.
- 무기군 / 몬스터 / 스타일 / 스타일강화 Lv20 / Lv10·15·20 파라미터 설정 후 최종 무기 수치로 방향을 추천한다.
- 방향 1~3개 + 직접 설정. 방향 선택은 핵심 스킬 프리셋을 채우고 자유롭게 수정 가능. 사용자 수정 내용은 무기 설정 변경으로 자동 덮어쓰지 않는다.
- 핵심 스킬 3개, 1→2→3순위. 기본 최소=max(1, MAX−2), 목표=MAX. 사용자 범위 조정 가능. 최소는 후보 자격 조건, 목표는 충족도 평가 기준. 장비 자체의 초과 레벨을 버리지는 않지만 평가 레벨은 목표까지다.
- 제한 내 많은 후보를 탐색하고 최대 5개 추천. 최소 미충족은 제외, 같은 방어구 조합 중복 제외, 스킬 우선순위순 / 빌드 점수순 정렬.
- 연성 사용/미사용. 슬롯당 Lv1, SMELT의 실제 스킬과 그룹을 사용. 핵심 부족분 보충 후 남은 슬롯의 소수 공격 후보 평가. 실제 넣은 연성만 점수에 포함하며 보유 연성은 아직 고려하지 않는다.
- 연성 사용 옆 ‘록온 필수’. 근접무기 선택 시 기본 ON, 라이트보우건/헤비보우건/활은 OFF·비활성화. ON이면 핵심 스킬 3개를 유지하고 내부 0순위 필수 조건으로 록온 Lv1을 확보한다. 단품 후보 선정·가지치기·연성 보충·최종 자격 검사에 반영하며 정렬 방식과 무관하게 미충족 후보는 제외한다. 기존 무기/장비로 충족하면 추가 확보하지 않고, 핵심 스킬에도 록온을 선택했으면 중복 요구하지 않는다. 초과 레벨은 가중하지 않는다.
- 기존 bdStats 점수 사용. 조건부 효과 발동 가정, 특수 위력 및 SP 전용 공격 효과 OFF. 가속 스킬은 후보와 핵심 스킬에서 유지하되 임의 대미지 배율로 환산하지 않는다. 각성의 일격은 개발 대상 제외. 포술/집중 추가 개발은 완료 처리.
- 무기별 운용 가이드는 사용자가 추후 제공. 플레이 경험 기반 필수·비권장 규칙을 임의로 확정하지 않는다.

## 현재 샘플 범위 및 한계

등록된 전체 몬스터·이벤트 소재 무기를 지원한다. 선택한 무기군에 해당하는 소재만 공식 방어구 순번으로 표시하며, 무기군 변경 시 해당 소재에 무기가 없으면 목록의 첫 소재로 전환한다. 소재 변경 시 스타일·강화·파라미터를 초기화하고 사용자 수정 핵심 스킬은 보존한다. 스타일/강화는 기존 BD_STYLE_DATA와 BD_STYLES 기준이다.

일반 속성 무기는 해당 속성 중심 / 회심 활용 샘플 프리셋을 사용한다. 최종 기본 회심 40% 이상이면 회심 활용을 먼저 표시하되 공식 최적 분기점은 아니다. 무속성·상태이상 무기는 운용 프리셋을 임의로 만들지 않고 '직접 설정'으로 핵심 스킬을 선택한다. 추가 연성 평가에도 해당 무기의 속성 강화만 사용한다. 카드 속성 아이콘·수치와 가져오기 이름은 실제 선택 무기에 맞춘다.

방어구 후보는 BUILD의 모든 세트다. 스타일별 운용, 보우건 탄별 방향이나 필수 장전/반동 기준, WEAPON_SETTING_GUIDE.md에 저장한 공통·랜스·상태이상 지침은 아직 실행 프리셋으로 옮기지 않았다. 문서 저장과 구현을 구분한다.

전체 방어구를 단품 평가한 뒤 핵심 스킬·점수 기준으로 부위별 최대 24개를 추린다. 그 조합을 단계별 beam(최대 160개 유지)으로 제한 탐색한다. 우선순위 경로와 점수 경로를 함께 보존하며 불가능한 최소 조건은 낙관적 상한으로 가지치기한다. 연성은 핵심 우선 / 점수 우선 두 경로로 보충한다. 전역 최적해나 모든 연성 조합을 보장하지 않는다. 브라우저 메인 스레드에서 짧은 단위로 양보하며 취소·설정 변경 시 이전 작업을 폐기한다. 제한 도달 및 탐색량을 화면에 표시한다.

조건부 효과 동시 발동 여부와 유지율은 미보정인 비교 점수다. SP 위력 OFF가 해금/기본 데이터 삭제를 의미하지 않는다. 사용자가 핵심 스킬로 SP 위력을 선택할 수는 있다. 추천 이후 내 빌드에서 체크를 바꿀 수 있다. 활 집중 사이클은 추천에서 미적용이며 기존 점수 기능 자체는 변경하지 않는다.

## 다음에 사용자에게 안내할 작성자료 양식

사용자가 ‘자동빌드 작성자료 기준’을 물으면 다음 양식을 안내한다. 잘 아는 무기·스타일부터 작성하면 된다.

1. 무기군 / 스타일 / 세팅 방향
2. 필수 스킬과 최소 레벨
3. 권장 스킬과 이유
4. 제외·비권장 스킬과 이유 (불필요와 적용 불가 구분)
5. 보우건 주력 탄종, 장전 속도·반동 경감 권장 레벨
6. 점수 계산에 사용할 조건부 효과
7. 핵심 스킬 충족 후 남은 연성 슬롯 추천 순서

사용자가 직접 선택한 스킬은 내부 권장보다 우선한다. 적용 불가는 별도 검증하며 비권장은 이유를 안내한다. 향후 규칙에 출처·확인일·사용자 검증 여부를 기록한다.

다음 단계는 사용자가 UI/추천 결과를 확인한 뒤 수정 방향을 정하는 것이다. 아직 전체 무기 운용 가이드나 전역 최적화를 완료한 서비스로 취급하지 않는다.

연성 배치 지침: 같은 스킬이 기본으로 붙어 있는 부위의 빈 슬롯을 우선 사용한다. 해당 부위가 없거나 슬롯이 부족하면 다른 부위에 배치한다. 핵심 최소 레벨 보충·추가 핵심 레벨·점수용 연성에 동일하게 적용하며, 기존 연성은 덮어쓰지 않는다. 재사용하기 좋은 배치를 위한 규칙이며 장비 조합의 점수·스킬 우선순위 자체는 변경하지 않는다.

추천 카드 표시: 장비명 옆에 몬스터명을 작게 표시하고, 바로 아래 한 영역에 기본 스킬과 연성 스킬을 함께 배치한다. 연성은 색상 보석 슬롯과 점선 테두리 스킬 칩으로 구분하며 별도 연성 행은 만들지 않는다. 계산 근거는 요구 스킬 충족(각 최소·목표·확보 레벨), 연성 배치, 점수 가정, 기대 점수로 나눈다.

계산 순서는 나우칼 간이 계산기(https://mhnowcalc.com/calc/damage_calc.php?lang=ko)의 공개식에 맞춘다. 공격 자동 상승분은 일반 배율 전에, 공격 파라미터는 배율 후에 더하며 공격 활성은 고정 증가분까지 곱한다. 회심격은 회심 분기의 일반 속성 배율에만 합산하고, 일반·회심 공격 대미지를 각각 구한 뒤 회심률로 평균한다. 상단 속성은 평균값이며 점수에 회심 기대배율을 중복 적용하지 않는다. 중간값은 반올림하지 않고 표시와 최종 점수만 반올림한다. 자동빌드도 같은 계산과 근거 표시를 공유한다. 상태이상 점수 모델과 약점·육질·모션·무기 고유 보정은 이번 변경 범위 밖이다.

추가 공격【독/마비/폭파】는 무기의 상태이상이 일치할 때만 계산하고 핵심 스킬 선택지에 제공한다. 슬래시액스의 독병·마비병도 해당 상태이상으로 인정한다. 파티원이 부여하는 상태이상은 이 비교 계산에서 가정하지 않는다. 무관한 추가 공격 스킬이 방어구에 함께 붙어 있더라도 점수 가산은 하지 않으며, 착용 스킬 목록 자체를 삭제하지는 않는다.
